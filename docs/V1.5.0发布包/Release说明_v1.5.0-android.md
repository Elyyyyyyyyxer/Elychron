## 这一版新增

- **PTA 作业自动进待办**：题目集的截止时间直接进待办，当堂实验与上机这类短窗口默认跳过，可在设置里打开
- **浙大图书馆预约进待办**：座位与研讨间带起止时间进日程，到点提醒签到；登录过一次后后台自动重登
- **校园服务**：紧急电话随包内置（断网可用）；普物实验课表可与教务来源切换

## 修掉的老毛病

- 「成绩推送已开启」不再因为覆盖安装而重复弹出（三处记账 + 独立低优先级通道）
- 提醒不再静默失败（启动时主动申请精确闹钟权限）
- 专注被杀后台后按墙上时钟静默接回，暂停可以离开页面
- 跨设备同步：课程资料不再互相翻倍，循环待办不再各长一条；坚果云 503 讲人话并自动退避
- 课表缓存可用：教务（zdbk）打不开时仍能看课表
- 界面：课程卡片按课程自动配色，长按任意卡片可隐藏全部文字；手机端去掉分组灰

## 安装

Android 传到手机点开安装，允许「未知来源」即可。iOS / iPadOS 请见另一个 Release（`v1.5.0.1-ios`）与其中的自签教程。

数据只存本地，同步走你自己的网盘（WebDAV）。升级前建议先用「设置 → 导出数据」留一份备份。
