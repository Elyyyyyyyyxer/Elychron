## 一、开发缘由

Celechron 是一款面向浙大学生的开源时间管理工具，可以查看课表、成绩、考试、作业等信息，同时允许学生自定义日程以便于规划学习生活。

在v1.3版本更新后，查看课表等数据不稳定的问题已经得到了大幅缓解，但是面对本科教务网失效、被神秘力量阻止访问等情况依旧无法及时查看课表，导致众多小白规划受到影响。同时，实用性较弱的DDL＆日程功能无法与市面成熟工具（系统日历、钉钉等）相提并论，日常使用便捷性不足，导致其处于一个比较尴尬的境地。

针对此类痛点，我针对性地大规模重写了日程功能，统一并细分了四种时间语义，接入了大语言模型，优化了提醒功能的实现，增设子待办细化任务流程，增设专注模式便于统计，增设备用课务数据来源，增设缓存备份机制，增强软件整体鲁棒性，打磨整体使用手感，最终以这一版差强人意的Elychron为名独立发行。

因为Elychron与原版Celechron差异巨大，已经不适合作为社区版本发布（否则易导致混淆和版本混乱，合并代码工作量巨大），因此选择独立发行（绝对不是因为我有私货）。

## 二、更新内容

### 1. 已有功能优化

- **增设eta获取数据渠道（issue#174）**，确保本科教务网不可用期间（譬如选课）也可以正常获得数据
- **空数据不再覆盖缓存（issue#174）**：教务明确返回空课表时不再把它写进缓存，而是沿用上一次成功解析的课表
- **校历多级回退**：远程配置 → 同学期缓存 → 本地推算，上游校历接口挂掉时只影响假期与考试周标注，课表照常显示
- **开学前也能看课表**：学期还没开始时直接显示新学期课表并提示开学日期，不再是干巴巴一句无学期信息
- **诊断与测试更有用**：刷新结果会写明「接口返回几行 / 解析入库几条 / 能显示几条」，出问题不用猜；一键导出**脱敏**日志，密码、Cookie、学号都会自动隐藏
- **重写时间设置模块**：现在的时间设置模块可以打开日程表，便于根据日历选择日期。同时，现在接受更加复杂的重复逻辑，自定义时间的自由性高度提升

### 2. 新增功能

**待办：四种时间语义 + 子待办行程表**

- **时间语义细化**：把原来笼统的日程/DDL合并为统一的待办，并再次细分为**活动 / 截止 / 提醒 / 备忘**四种时间语义，各自的提醒时间、逾期判定、日历表现都不同。活动类拥有完整起止时间，提醒时间默认开始前30分钟，等效为原版本日程；截止类只有截止时刻，等效为原版本DDL；提醒类仅有提醒时间，可用于便捷通知；备忘类无时间、无提醒，充当备忘录使用
- **新增子待办功能**：一个待办现在可以添加多个子待办。子待办分为清单类与日程类，清单类没有时间，默认提前显示；日程类拥有起止时间，可自动排序形成日程表

![](https://file.cc98.org/v4-upload/d/2026/0913/owinubcl.webp)

- **新增附件、优先级、标签功能**：待办里现在可以添加附件了，方便查找任务需要的信息。优先级可以参与待办分类，方便自主规划与分类整理待办。添加标签库，方便大批量整理与查看待办
- **新增评论功能**：在长程任务中用于自定义记录实时情况，或者其他任何想记下来的东西，方便数字留痕
- **新增待办页筛选器**：现在在待办页面可以根据时间语义、创建时间、标签等等对待办进行筛选查看，再也不用疯狂翻页了
- **删除功能增加二次确认**：字面意思，防止手滑
- **合并原接下来与日程页**：现在你可以通过屏幕顶部的圆形按键进行翻页切换了，默认打开接下来页面

**AI 整理（默认关闭，自带 Key）**

- **全自动日程转换**：把一段通知、聊天记录、邮件，甚至一张截图，整理成结构化待办：标题、描述、类型、时间、地点、标签、子待办一次到位
- **自动拆解子待办**：将复杂任务拆解为可执行的步骤链条，有效化解畏难情绪
- **功能默认关闭**：开启需填自己的模型服务商 Key（当前版本仅支持 DeepSeek），内容只发给你自己配置的服务商

![](https://file.cc98.org/v4-upload/d/2026/0913/cpjehewx.webp)


**待办页：钉钉风格的重做**

- **分类页签**：待我处理 / 优先处理 / 我已处理 / 星标
- **标签体系**：可新建、删除、**拖动排序**、**每个标签单独配色**（10 色盘）；标签筛选可多选

![](https://file.cc98.org/v4-upload/d/2026/0913/qxmtu0sr.webp)

**提醒与闹钟**

- **提醒方式可选**：**通知**（横幅 + 响铃）或**全屏闹钟**（全屏弹出 + 循环系统闹钟铃声 + 震动，可延迟 10 分钟或划掉）
- **四套闹钟配色预设（天依蓝 / 爱莉粉 / 清新绿 / 静谧紫）**：设置里可预览真实页面，后续预计添加更多配色
- **新增闹钟可靠性自检页**：全屏闹钟授权、通知渠道重要度、电池优化白名单检查，没开的可以直接跳转设置（国产 ROM 杀后台是闹钟不响的头号原因）
- **可选系统时钟提醒功能**：重点事项可以半自动设置为系统闹钟。待办详情 → 右上角⋯ →设为系统闹钟。一次性、且**不会随待办完成/删除而撤销**，要改要删得自己去时钟应用操作 

**专注模式**

- **新增专注页**：增设专注模式，用于统计各事务真实时间消耗。此模式下进入工作/休息循环，可以指定待办或自由新建临时任务进行专注。在专注页可以查看详细的专注模式统计数据，有效助力时间管理与统筹规划
- **工作 / 休息自动交替**：（默认 1 小时 / 15 分钟，可改），工作段走完弹通知提醒你起来走走
- **专注记录**：今天 / 本周 / 本月时长、最近七天趋势、按任务分布

![](https://file.cc98.org/v4-upload/d/2026/0913/tuon2pvo.webp)

**其它**

- **跨应用联动**：其它应用分享图片/文件/文字进来即可新建待办
- **待办 JSON 导出 / 导入**：按 uid + 更新时间合并（不是覆盖），删除留墓碑，便于数据迁移

## 四、数据迁移（重要！！！）

**从官方版迁过来**：课表、成绩、考试、作业、素质拓展、校园卡**登录同一个学校账号就有**，不用搬。要手动处理的只有你自己手写的待办，官方版没有数据导出功能，这部分得重建，建议在待办页截屏后选择AI生成待办

## 五、已知问题

- 只提供 arm64 包
- **局域网直连网页端尚未开放**，为后续开发目标，当前版本不可使用
- 跨网络同步（坚果云 / WebDAV）只有预留配置项，功能未实现
- 校历配置仍依赖上游的公开只读接口，挂了会回退到缓存 / 本地推算
- AI 功能需要自备模型服务商的 Key
