# v1.5.0 桌面端：安卓专属功能怎么办

> 2026-09-18 起进入 v1.5.0（桌面端是后面的多端基座）。这一页是**能力对照表**，
> 也是"哪些要你拍板"的清单。判据统一在 `lib/utils/platform_features.dart`。

## 一、已经用另一套做法实现的

| 安卓上的做法 | 桌面端 | 状态 |
| --- | --- | --- |
| 写系统日历（device_calendar 插件） | **导出 .ics**（写入"下载"目录，Outlook / 谷歌日历 / 苹果日历都能导入） | 已实现（设置 → 日程 → 导出课表（.ics）） |
| 闹钟铃声（原生循环播放） | 系统提示音兜底（`SystemSound.alert`）+ 闹钟界面照常弹出 | 已实现（"循环响"见待拍板） |
| 后台定时刷新（WorkManager） | 桌面常驻前台，不注册后台任务 | 已实现（安静跳过） |
| 记录同步用的时间戳 | 桌面端用 `SystemClock` 无关的普通定时器 / 前台刷新 | 已实现 |
| 数据存储（Hive + 系统密钥库） | 一样能用：Hive 走文件、`flutter_secure_storage` 在 Windows 上走凭据管理器 | 无需改动 |
| 打开链接 / 打开导出文件夹 | `url_launcher`（Windows 有实现） | 已实现 |

## 二、暂时做成"壳子"（安静跳过 + 界面写明）

| 能力 | 桌面端现状 | 说明 |
| --- | --- | --- |
| 系统通知（提醒 / 闹钟响铃） | **壳子**：`PlatformFeatures.hasSystemNotifications` 为 false，初始化直接跳过 | 现在用的 `flutter_local_notifications` 没有 Windows 实现；应用内提醒照常，只是不出系统通知 |
| 闹钟渠道 / 全屏通知 / 电池优化白名单 | **壳子**：相关设置项在桌面端不显示 | 这几样是安卓系统概念，桌面没有对应物 |
| 系统免打扰（专注时静音） | **壳子**：`hasDoNotDisturb` 为 false，写操作直接返回 false | Windows 的"专注助手"是另一套 API，没接 |
| 桌面小组件（最近待办 / 校园卡） | **壳子**：`hasHomeWidgets` 为 false，不推送快照 | 桌面上没有 AppWidget 这种东西 |
| 从其它应用"分享进来" | **壳子**：`canReceiveShares` 为 false，不监听通道 | 桌面可以改成拖文件进窗口 / 文件关联 / 命令行参数 |
| 读取设备型号（反馈信息里那一行） | **壳子**：桌面端插件没实现，那段不写 | 反馈信息其余部分照常 |

## 三、需要你拍板的（按影响排序）

1. **本机缺 MSVC**：`flutter build windows` 现在**跑不起来** —— 这台机器没有 Visual Studio / Build Tools（我查过：没有 vswhere、没有 cl.exe，只有 mingw 的 cmake/ninja，而 Flutter 桌面只认 MSVC）。
   → 需要装 [Visual Studio 2022 Build Tools] + "使用 C++ 的桌面开发" 工作负载（约 7 GB）。
   装完我就能真机跑起来验收桌面端；**在那之前桌面端只能靠 analyze + 单测保证，不能真跑**。
2. **桌面端系统通知怎么办**：换一个支持 Windows 的通知包 / 自己写 Windows Toast（需要 MSIX 打包或 AUMID）/ v1.5.0 先不做。
3. **闹钟要不要在桌面端"循环响"**：引第三方音频包（如 `audioplayers`，多一个依赖）/ 写 Windows 原生播放 / 保持"响一声 + 界面弹出"。
4. **桌面布局**：现在是把手机那套 Cupertino UI 直接拉宽到窗口里（能用，但不是桌面该有的样子）。
   要不要做：左侧导航 + 右侧内容、多窗口、快捷键（`⌘/Ctrl+N` 新建待办等）、托盘常驻？
5. **"分享进来"换成什么**：拖拽文件进窗口 / 给 .ics 等文件做关联 / 命令行长这样 / 都不做。
6. **要不要顺带把 Linux / macOS 也纳入维护**（骨架已经在了），以及帖子裡承诺的**浏览器端**（Web 版）算不算 v1.5.0 的范围。
7. **局域网同步**：现在有一份 `lib/mod/lan_sync_server.dart`（纯 Dart，桌面端天然可用）。要不要在桌面端先把它变成"手机 ↔ 电脑互传"的正式功能？

## 四、这一轮改了什么（技术细节）

- 新增/扩充 `lib/utils/platform_features.dart`：一张平台能力表（原来只有 4 个 getter，现在把"桌面怎么办"逐项写清）。
- 所有安卓专属调用点改成先问这张表：
  `share_receiver`（分享）、`do_not_disturb`（免打扰）、`alarm_player`（铃声 / 渠道 / 全屏通知）、
  `ecard_widget_messenger`（校园卡小组件）、`main.dart`（通知初始化）、
  `background_app_refresh`（WorkManager）、`calendar_to_system`（device_calendar）。
- 新增 `CalendarToIcal.exportIcsToDisk`：桌面端把 .ics 写进"下载"目录并把路径告诉用户（手机端照旧走分享面板）。
- 设置页在桌面端把"同步到系统日历"换成"导出课表（.ics）"。
