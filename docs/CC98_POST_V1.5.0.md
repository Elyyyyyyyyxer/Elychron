**【全平台通用】Elychron V1.5.0：全面 SOTA，优于 Celechron 的浙大日程软件。全平台免费同步，全天候课表稳定性，强大日程系统，支持普物实验，学在浙大作业，PTA，图书馆**

> Celechron 的非官方改版，与官方版**包名不同、可以共存**，装它不会覆盖官方版。遵循 GPLv3，源码即本仓库。

## 一、Elychron 是什么

一句话：把浙大同学平时要在五六个网站之间来回切换的东西，收进同一个 App。课表与日程、待办与作业、专注计时、成绩学分、校园服务、图书馆预约，外加一个你自己配置的 AI 助手。数据全部存在你自己的设备上，同步走你自己的网盘，没有中间服务器。

支持 Android、Windows 桌面版、iPhone / iPad（需自签），网页版正在做。

## 二、功能总览

### 课表与日程

周课表一周十三节，按月历视图还能看到农历、节气、节假日与调休标记，两门课时间冲突会直接指出来。日程页支持上月 / 下月 / 今天 / 课表一键切换。课程卡片按课程自动配色，同一个课程颜色固定，长按任意卡片可以把所有卡片上的文字藏起来，只留颜色看形状。

### 待办系统

四种时间语义分开处理：**活动**（有明确起止）、**截止**（到点必须交）、**提醒**（提前叫你）、**备忘**（没有具体时间）。可以只写一个大致时段，不必每件事都精确到分钟。待办可以拆子待办、排成一段行程、打标签分组、批量编辑、下拉刷新。附件支持文件、图片与链接。

### 专注

工作与休息轮换计时，开始时会自动按当前那一节课记下课程归属，统计页能看到今天 / 本周 / 本月时长，以及本月按课程的分布。被杀后台或系统冻结后回到前台会静默接回来继续计时；暂停后可以离开专注页去改待办、回消息，回来还在。专注时自动免打扰，休息段自动还原。

### 学业

四张卡片：**成绩**（五分制 / 四分制 / 百分制、主修均绩、已修学分，一键隐藏绩点）、**课程**（学分与考试安排）、**作业**（学在浙大上的作业，按一天内 / 本周截止分组）、**实践**（第二、三、四课堂记点）。顶部可切学期，每张卡片标了数据更新时间。

### 校园服务

**紧急电话**：各校区报警、急诊、各单位的电话随包内置，断网也能看，点一下直接拨。

**普物实验**：物理实验的预约与安排，可以切换数据来源（教务 / 物理实验平台）。

**学在浙大**：课程与作业通知直接进待办。

**PTA（拼题A）**：题目集的截止时间自动进待办，当堂实验与上机这类短窗口的默认跳过（可在设置里打开）。用内置浏览器登录一次即可。

**图书馆**：座位与研讨间的预约带起止时间进日程，到点提醒你去签到；登录过一次之后后台会自动重登。

**素拓与研究生院**：第二课堂记点、研究生培养与选课信息。

### AI 助手（默认关闭）

填你自己的模型 Key（目前支持 DeepSeek）。把一段通知粘进来，它会拆成几条待办；也能读截图与图片，大任务可以拆成可执行的子步骤。默认关闭，开启后只把你选中的内容发给你自己配置的服务商。

### 同步与备份

WebDAV 同步，坚果云、InfiniCloud、Koofr、Nextcloud、群晖、Alist 都行，不需要订阅；同一 Wi-Fi 下的设备还能局域网直连。支持导出 / 导入 JSON 备份，也支持把别的日历导出的 iCal（.ics）导入成待办，按 UID 去重。两台设备同时用时，课程资料与循环待办不会再互相翻倍。

### 通知

上课与待办提醒走精确闹钟，「提醒已开启」这类开场白只在真正需要时说一次，不会反复弹。iOS 26 及以上可以在待办详情里创建一次性的系统闹钟，旧系统回退到本地通知。需要报问题时，「设置 → 数据 → 复制反馈信息」会一次把机型、系统版本、App 版本与最近 120 行脱敏日志复制到剪贴板。

### 稳定性

课表与成绩有本地缓存，教务（zdbk）打不开时照样能看课表；数据来源有多条通路，一条不通会自动换下一条；更新检查按 GitHub → Gitee 的顺序尝试，提示有新版本时「去下载」会打开实际回应的那个源。

## 三、安装

**Android**：下载 `Elychron-v1.5.0-android-arm64.apk`（约 28.5 MB，只需 arm64），装的时候允许「未知来源」即可。包名与官方版不同，两者可以共存。

**Windows**：下载桌面版压缩包，解压后双击 `Elychron.exe`，绿色免安装（整个文件夹要一起保留）。

**iPhone / iPad**：我们没有苹果开发者账号，需要你用**自己的 Apple 账号签一次名**（AltStore，免费账号 7 天续签一次，数据不会丢）。完整步骤见 Releases 里的 `iOS自签安装教程`，也附了 HTML 与 PDF 版本。这一版 iOS 侧带分享扩展（把内容分享给 Elychron 直接存成待办）与待办、校园卡两个小组件，iPad 在宽窗口下是五栏侧边栏。

**下载渠道**：GitHub Releases、Gitee、夸克网盘（提取码 ph1z）、百度网盘知识库，以及可用的 GitHub 镜像 `gh-proxy.com`。官网 <https://elychron.pages.dev> 上列了全部入口。

## 四、数据迁移（重要！！！）

从官方 Celechron 或更早的 Elychron 迁过来：先在旧版本里「设置 → 导出数据」导出 JSON，再在新版本里导入，待办、标签、设置都会带过来。**不要先卸载旧版**，确认新版本正常之后再删。

iOS 要特别留意：换 Apple 账号、或者从 Xcode 安装切换到 AltStore，可能被当成一个新应用装上去，旧容器与钥匙串里的登录信息不保证自动迁移。装之前先导出备份。

## 五、已知问题

iOS 必须自签，免费账号 7 天续签一次；本轮的 iOS 验证到模拟器为止，真机自签、续签与完整交互还没有走完验收，遇到问题请回报。普物实验与图书馆这类校内服务需要手机自己在校园网或学校 VPN 里，不能借电脑的代理。鸿蒙目前没有原生版，可以先用网页版。
