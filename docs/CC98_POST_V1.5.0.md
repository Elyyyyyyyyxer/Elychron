## 一、为什么敢说全面 SOTA、优于 Celechron？

原版 Celechron 已经实现了基本的看课表功能，但是日程功能仍然极不实用。同时，欠佳的稳定性导致很多时候出现白屏的问题，普物实验也无法导入。我们需要更新、更强、更稳定的日程软件！

为了达到这个目标，Elychron 充分满足了众多需求：全天候课表稳定查看，全面强化的待办系统（好评如潮.jpg），自动提取线上作业成为待办，全平台免费同步，大模型自动生成待办等等超级多实用高效的功能！迈入V1.5.0，Elychron 已经足够成熟，在日常生活中达到了无需校准即可趁手的水准，特此发布！

目前支持的平台：鸿蒙（非原生）、Android、Windows 桌面版、iPhone / iPad，网页版（开发中）

## 二、功能详解

### 1. 学校信息的超绝稳定性

1. **稳定性超群**：采用 ETA，zdbk，本地缓存和防限流机制，课表、学分、二三四课堂分、作业等等可以保证全天候在线可查；

2. **日程可视性提升**：日历**可折叠**以便查看，通过翻转卡片查看日历/当天；

3. 课程可挂载**待办、图片、文件等等**，再也不用为找不到长期项目担忧。

### 2. 对标市面成熟工具的待办系统

1. **四类待办分类**：Elychron 拥有**活动 / 截止 / 提醒 / 备忘**四种时间语义，便于行程2规划：活动有明确的起止（上课、做实验）；截止到点必须交的东西（作业、报告）；提醒是提前叫你一声；备忘则不包含具体时间，任何小事都可以塞进去；

2. **专用待办筛选器**：允许对待办进行**时间、标签、优先级等等**进行分类查看，极大程度方便任务管理；

3. 独特**子待办系统**：同一个待办下可以挂载多个带时间/无时间子待办，自动按时间排序，形成长时间日程表、TODO list，便于长任务规划；

4. **文件挂载**：所有待办都可以挂在课程上，所属类型一目了然。所有待办都可以挂载图片、文件，规划作业非常实用！

5. **AI待办（强推！）**：填写API密钥后，任意图片、通知均可以一键生成待办，带多个子待办进行任务规划。已经达到**实用级**标准，生成即用。

### 3. 专注

1. **时间规划神器**：工作段与休息段轮换计时，默认45/5。能够按照**开始时所属课程**计入课程归属（可在设置里关掉），统计页因此能看到"这门课我总共花了多少时间"；

2. **统计面板**：统计给出今天、本周、本月的专注时长，以及本月按课程、待办的分布。

### 4. 学业

1. **全面信息显示**：四张卡片展现校园所有需求。**成绩**支持五分制、四分制、百分制，给出主修均绩与已修学分；**课程**给出这学期修了多少门、多少学分、考试怎么安排；**作业**把学在浙大上的作业按"一天内截止""本周截止"分好组；**实践**是第二、三、四课堂的记点情况。顶部可以切换学期。

### 5. 校园服务

1. **紧急电话**：各校区的报警、急诊、各单位电话随包内置，点一下直接拨号；

2. **普物实验（在设置中登录）**：物理实验的预约与安排直接读取列入日程；数据来源可以切换（教务或实验平台），双通道备份兜底；

3. **学在浙大（在设置中登录）**：课程与作业通知自动进待办，开箱即用；

4. **PTA（在设置中登录）**：题集作业自动进待办。当堂实验、上机这类几小时内就结束的短期任务默认跳过；

5. **图书馆（在设置中登录）**：座位与研讨间的预约带起止时间进日程，到点提醒去签到。注意：图书馆系统只允许单设备登录，记得检查有没有掉登录；

6. **素拓与研究生院**：第二课堂记点、研究生培养与选课信息，信息全面可靠！

### 6. AI 助手（默认关闭）

在设置里填你自己的模型 Key（目前支持 DeepSeek），它能把一段通知或文字拆成几条带时间与类型的待办，也能读截图与图片，遇到大任务会拆成可执行的子步骤。默认关闭；开启后也只把你选中的那段内容发给你自己配置的服务商，其余数据不出设备。

### 7. 同步与备份

同步走你自己的网盘（WebDAV）：坚果云、InfiniCloud、Koofr、Nextcloud、群晖、Alist 都可以，不需要订阅。同一 Wi-Fi 下的设备还能局域网直连，速度更快。支持导出与导入 JSON 备份；也支持把别的日历导出的 iCal（.ics）导入成待办，按 UID 去重，重复导入不会产生重复条目。两台设备同时使用时，课程资料与循环待办不会再互相翻倍（这两个坑在 1.5.0 里修掉了）。坚果云偶尔返回 503 是在限流，现在会讲人话并自动退避半小时再试。

### 8. 通知

上课提醒与待办提醒走精确闹钟。像「提醒已开启」这类开场白只在真正需要时说一次，不会反复弹；成绩变动的通知有独立的去重窗口，重复的不会再推。iOS 26 及以上可以在待办详情里创建一次性的系统闹钟，旧系统回退到本地通知。报问题时，设置里「数据 → 复制反馈信息」会一次把机型、系统版本、App 版本与最近 120 行**脱敏**日志复制到剪贴板（密码、Cookie、学号已隐去），粘到帖子里就行。

### 9. 界面与细节

手机端设置、学业、待办编辑与搜索页统一成白色，去掉了常见的分组灰；桌面端换上爱莉图标与 HarmonyOS Sans SC 字体（字体用系统已安装的，不塞进安装包）；应用内带七篇中文教程，边看边点。

### 10. 稳定性

课表与成绩有本地缓存，**教务（zdbk）打不开的时候照样能看课表**，这是很多人换到这个版本的主要原因。数据来源有多条通路，一条不通会自动换下一条。更新检查按 GitHub → Gitee 的顺序尝试，提示有新版本时「去下载」会打开实际回应的那个源，不会出现"说有新版却打不开下载页"。

## 三、安装

**Android**：下载 `Elychron-v1.5.0-android-arm64.apk`（约 28.6 MB，只需 arm64，近年的校园机型都支持），传到手机点开安装，允许「未知来源」即可。鸿蒙手机可以用**卓易通**打开安装。包名与官方 Celechron 不同，两者可以共存。

**Windows**：下载桌面版压缩包，解压后双击 `Elychron.exe`，绿色免安装；整个文件夹要一起保留，exe 旁边的 dll 与 data 目录都是运行需要的。桌面版没有 PTA 与图书馆这两个功能（它们依赖手机上的内置浏览器登录），其余功能与手机一致。

**iPhone / iPad**：我们没有苹果开发者账号，需要你用**自己的 Apple 账号签一次名**（AltStore，免费账号 7 天续签一次，数据不会丢）。完整步骤见 Release 里的 `iOS自签安装教程`，同时附了 HTML 与 PDF 两个版本。这一版 iOS 侧带分享扩展（把文字、图片、文件分享给 Elychron 直接存成待办）与待办、校园卡两个小组件，iPad 在宽窗口下是五栏侧边栏、窄窗口仍是底部标签栏。

**下载渠道**：GitHub Releases、Gitee、夸克网盘（提取码 ph1z）、百度网盘知识库，以及实测可用的 GitHub 镜像 `gh-proxy.com`。上面两个官网都列了全部入口。

## 四、数据迁移（重要！！！）

从官方 Celechron 或更早的 Elychron 迁过来：先在旧版本里「设置 → 导出数据」导出 JSON 文件，再在新版本里「导入数据」导入，待办、标签、设置都会带过来。**不要先卸载旧版**，确认新版本能正常用之后再删。

iOS 要特别留意：换 Apple 账号、或者从 Xcode 安装切换到 AltStore，可能被当成一个新应用装上去，旧容器与钥匙串里的登录信息不保证自动迁移。装之前先导出备份，旧应用先别删。

## 五、已知问题与限制

iOS 必须自签，免费账号 7 天续签一次；本轮的 iOS 验证到模拟器为止，真机自签、续签与完整交互还没有走完验收，遇到问题欢迎回报。普物实验、图书馆这类校内服务需要手机自己在校园网或学校 VPN 里，不能借电脑的代理。鸿蒙目前没有原生版，可以用卓易通装 Android 包，或者等网页版。
