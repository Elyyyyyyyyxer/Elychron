**【开源更新】Elychron 1.5.0：iOS 原生版可以自签安装了，PTA 作业和图书馆预约也会自己进待办**

> Celechron 的非官方改版，与官方版**包名不同、可以共存**，装它不会覆盖官方版。遵循 GPLv3，源码即本仓库。

## 一、开发缘由

这个改版从 1.4.0 开始发，到现在两个月。1.5.0 主要补三件事：iOS 一直没有原生版，这次做了；同学反馈最多的"作业要手动抄一遍""图书馆约了座忘了签到"，这次让它们自己进待办；还有一堆通知与同步上的老毛病，这次一并修掉。

## 二、更新内容

### 1. 已有功能优化

**通知不再反复打扰你。**「成绩推送已开启」这条开场白原来记在后台任务的加密存储里，而覆盖安装后密钥库读空、记录丢失，于是它反复弹——有同学说"一天给我推送很多次"。现在三处一起记、以数据库为准，并换到独立的低优先级通道，不再弹横幅。提醒本身也修了一个坑：精确闹钟的权限原来挂在被删除的设置页上，导致重装后提醒静默失败，现在启动时主动申请。

**专注被杀后台后能自己接回来。**记录的是一段段状态（工作 / 休息 / 暂停），回到前台后按墙上时钟逐段推进，直接接着跑，不问你；暂停超过 12 小时会自动结算，那段时长照常计入统计。

**跨设备同步修了两处会"翻倍"的地方。**课程资料原来按本机路径判断重复，而每台设备的下载文件名都带自己的时间戳，于是同一个文件在两台设备上互相翻倍（有人截图里一张图出现了四次）；循环待办原来用本机随机 id，两台各长一条（"电脑端有两个洗头"）。现在前者按名字与大小判断，后者按来源与到期时间折叠。坚果云的 503 查清是限流，现在会讲人话并自动退避 30 分钟。

**界面细节。**手机端设置、学业、待办编辑与搜索页统一成白色，去掉中间的灰；课程卡片改成按课程自动取色的粉色系，同一门课颜色不变、相邻两门分得开；长按任意课程卡片可以把所有卡片上的文字藏起来，只看颜色；桌面端换上爱莉图标与 HarmonyOS Sans SC 字体；待办页支持下拉刷新（等于立刻跨设备同步一次）。

### 2. 新增功能

**iOS / iPad 原生版。**主应用之外还有分享扩展（把文字、图片、文件分享给 Elychron 直接存成待办）与两个小组件（待办、校园卡）。iPad 在宽窗口下改成五栏侧边栏、内容居中限宽，窄窗口仍是底部标签栏。iOS 26 及以上可以在待办详情里创建一次性的系统闹钟，旧系统回退到本地通知。这一版还修了钥匙串的一处问题：Profile 构建原来误用了 Release 的钥匙串分组，现在 Debug / Profile 用 debug 组、Release 用 release 组，并且启动时会实际探测权限、缺失时回退私有组，登录不会因此卡死。

**iOS 需要你自己签名。**我们没有苹果开发者账号，所以提供的是脱敏的 IPA，你用**自己的 Apple 账号**签一次名就能装（AltStore，免费账号 7 天续签一次，数据不会丢）。完整步骤写在仓库 `docs/ios-self-sign-guide.md`，Release 里也附了一份。

**PTA（拼题A）作业自动进待办。**题目集的截止时间会变成待办，当堂实验 / 上机这类短窗口的默认跳过（可在设置里打开）。登录用内置浏览器正常登录一次即可，凭据不进日志。

**浙大图书馆的预约进待办。**座位和研讨间的预约带起止时间，直接进日程、到点提醒你去签到。它和图书馆系统之间是单设备登录：你在别的设备上再登录一次，这边会被顶掉，界面会原样显示服务端那句「请注意,您的账号在其他设备登录！」，重登一次就好。登录过一次之后，后台会自动重登，不需要你每次手动。

**官网与下载镜像。**网站是 `elychron.pages.dev`，列出了各个下载渠道：GitHub Releases、Gitee、夸克网盘（提取码 ph1z）、百度网盘知识库，以及一个可用的 GitHub 镜像（`gh-proxy.com`）。网站本身没有统计脚本。网页版（PWA）已经可以作为 iPhone 的临时方案用起来。

## 三、安装与数据

Android：下载 `Elychron-v1.5.0-android-arm64.apk`（约 28.5 MB，只需 arm64，近年的校园机型都支持），安装时允许「未知来源」即可。

iOS / iPad：从 Release 下载 IPA，按 `iOS自签安装教程.md` 自签安装。装之前建议核对一下 SHA-256。

Windows：桌面版目前需要按仓库 README 的「六、构建」自行编译，我们暂时没有提供官方安装包。

所有数据（待办、课表、设置）都只存在你自己的设备上，同步走你自己的网盘（WebDAV：坚果云、InfiniCloud、Koofr、Nextcloud、群晖、Alist 都行）。Elychron 没有服务器，也不收集任何数据。

## 四、数据迁移（重要！！！）

从官方 Celechron 或更早的 Elychron 迁过来：先在旧版本里「设置 → 导出数据」导出 JSON，再在新版本里导入，待办、标签、设置都会带过来。**不要直接卸载旧版**，确认新版本正常之后再删。

iOS 这边要特别注意：换 Apple 账号、或者从 Xcode 安装切换到 AltStore，可能被当成一个新应用装上去，旧容器与钥匙串里的登录信息不保证自动迁移。装之前先导出备份。

## 五、已知问题

iOS 版必须自签，免费账号 7 天续签一次；本轮的 iOS 验证到模拟器为止，**真机自签、续签与完整交互还没有走完验收**，遇到问题请回报。普物实验、图书馆这类校内服务需要手机自己在校园网或学校 VPN 里，不能借电脑的代理。鸿蒙目前没有原生版，可以先用网页版。

## 六、反馈

在帖子下回复，或者到仓库开 Issue。报问题时建议用「设置 → 数据 → 复制反馈信息」，它会把机型、系统版本、App 版本和最近 120 行**脱敏**日志一起复制到剪贴板（密码、Cookie、学号已隐去），直接粘过来就够。

## 七、后续开发方向

网页版（PWA）继续做，让不想自签的 iPhone 用户也能用上主要功能；桌面端体验与稳定性继续打磨；鸿蒙原生版的成本还在评估，暂时没有时间表。
