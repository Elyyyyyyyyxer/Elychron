## 二、这一版做了什么（逐条对应）

| # | 反馈 | 这一版的处理 |
|---|---|---|
| 1 | 活动类不能右滑 | 活动 / 日程 / 截止**都能右滑完成与恢复**，行为统一 |
| 2 | 卡片叠了不会切 | 点卡边弹出列表选一条换到顶层；点错能点回来 |
| 3 | 「划掉」没反应 | 那个按钮原来声明成"纯后台动作"，现在走前台：通知取消、闹钟页关闭、铃声停止 |
| 4 | 闹钟重复弹 | 去重改成按**提醒时刻**，关掉、重启都不会再弹 |
| 5 | 学业页空白、反复报错 | 判据里的空断言已改成判空；**半坏的登录态也一并修了** |
| 6 | 登录态诡异 | ①「已登录但学号读不到」不再崩；② 登录失效**如实显示**并给一键重登；③ **账号密码永远能预填**（镜像进数据库，换设备/系统失忆都不怕） |
| 7 | 密码框弹不出键盘 | 密码框显式声明为可见密码类型、关掉自动更正与建议，并加了**「显示密码」眼睛开关**（明文一般就能弹出来）。⚠️ 我们没有小米设备，**等你回访确认** |
| 8 | 翻页太灵敏 | 要划够约 1/4 屏宽才翻页 |
| 9 | 底部被遮挡 | 课程详情、考试详情等页面统一留出底部安全内衬 |
| 10 | 要批量操作 | 待办页 ⋯ → **批量编辑**：多选批量完成 / 删除（会记墓碑，多端合并不会"复活"） |
| 11 | App 打不开 | **数据安全加固**：盒子文件损坏时先整份留档再重建、绝不静默清空；开机发现"上次卡在某个盒子上"会先挪走再开。**这次事故里 32 条待办全部找回** |
| 12 | 半学期归属 | 研究生/自定义重复那条路径已修（单半学期 + 周次 ≤ 8 按它自己那一半算） |

## 三、这一版新增的东西

- **课程挂载**：点开一门课，能看到挂在它下面的**资料 / 评论 / 待办**；待办可「挂到某门课」
- **专注按课程统计**：统计页新增「本月按课程」；专注开始时按开始时刻的那节课自动归属（可关）
- **AI 生成待办带课程**：只有原文**明确提到课程**时才挂，课表里找不到会提示
- **iCal（.ics）导入**：别的日历/课表导出的 .ics 直接导成待办，按 UID 去重
- **分享到「已有待办」**：分享进来的文字/图片可以追加到某条已有待办
- **专注时自动免打扰**（可关）：专注段静音、休息段自动还原
- **国内也能收到更新**：更新检查 GitHub → Gitee 依次尝试，「去下载」打开真正回应的那个源
- **一键「复制反馈信息」**：机型 / 系统 / 版本 + 最近 120 行**脱敏**日志 + 反馈模板
- **使用教程**：设置 → 教程，三分钟过一遍主要功能

## 四、已知问题

- 只提供 **arm64** 包（近年校园机型都支持）
- **桌面小组件「最近待办」（PR #4）本版暂未开放**：它的刷新依赖系统后台调度，
  在「电池优化」限制下会「点了勾选、画面不刷新」。与其发一个时灵时不灵的功能，
  不如等有解再开 —— 本版里**它的入口是关闭的**
- **局域网直连网页端仍不可用**，是后续开发目标
- 跨网络同步（坚果云 / WebDAV）只有预留配置项，功能未实现
- 校历配置依赖上游只读公开接口，挂了会回退到缓存 / 本地推算
- AI 功能需要自备模型服务商的 Key
- 提醒的可靠性受系统后台限制影响：**设置 → 闹钟可靠性**里可以逐条自查（全屏闹钟授权、
  通知渠道重要度、电池优化白名单）。同一份白名单也管着后台刷新等一切"App 不在前台也要干活"的事
