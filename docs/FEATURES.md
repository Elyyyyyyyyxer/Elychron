# Elychron 功能教程

> 按「你会怎么用它」来写，不是按代码模块。每条都写了**在哪、怎么操作、会得到什么**。

## 一、四种时间语义（这是 Elychron 的地基）

官方版只有「任务 / DDL」一种时间概念，Elychron 把「时间」拆成四种，
因为**同样是"9 点"**，「9 点开始考试」和「9 点前交作业」完全是两回事。

打开任意待办详情，中间那排就是类型选择：

| 类型 | 用在哪 | 时间怎么填 | 提醒锚点 | 在日历里 |
|---|---|---|---|---|
| **活动** | 典礼、会议、考试、讲座、面试 | 有开始 + 结束 | **开始时刻**前 N 分钟 | 占一段时间 |
| **截止** | 交作业、交报告、报名、缴费 | 只有截止时刻 | **截止时刻**前 N 分钟 | 不占时段 |
| **提醒** | 「9 点去取快递」「3 点打电话」 | 就那一刻 | **就在那一刻** | 不占时段 |
| **备忘** | 「记得买牙膏」 | 不设时间 | **不提醒** | 不进日历 |

几个自动行为：

- **备忘**永不逾期、不提醒、不进日历 —— 它就是一张便签，不会在列表里变红
- **截止**过期才标红（不是快到了就红）
- **活动**的提醒锚在开始时刻，所以「17:45 集合」的提醒会落在 17:15（默认提前 30 分钟）

> 从别处粘贴一段通知进来时，AI 会自动判断属于哪一种（见「AI 整理」）。
> 拿不准时它会按「截止」处理，并把不确定的字段列进 `uncertain`。

## 二、子待办 = 行程表（不是勾选清单）

官方版的子任务只是打钩清单；Elychron 的**每一步都能带时间**。

在待办详情里点「添加子待办」，每一步可以设：

- **开始 / 结束时间** —— 这一步单独占的时段
- **提前提醒分钟数** —— 留空则沿用「设置 → 默认提醒提前量」
- **完成状态** —— 单独打钩，主待办会显示进度（如 `子待办 2/4`）

于是「开学典礼」这种待办在手机上是这样的：

```text
参加新生开学典礼          ⏰ 17:15 提醒
├─ 17:45  到紫云篮球场集合        ⏰ 会在 17:15 提醒
├─ 18:00  随领队入场
├─ 20:30  参加互动环节            ⏰ 会在 20:00 提醒
└─ 带雨伞                          （清单型：没有时间）
```

**两种子待办**：

- **行程型**：有时间 → 会参与「进行中 / 已超时」判断、能单独提醒
- **清单型**：没有时间 → 就是一条要打钩的事项（`带校徽`、`穿白色院衫`、`带雨伞`）

待办列表页会直接显示「下一步 17:45 到紫云篮球场集合」，不用点进去看。

## 三、待办页：分类、标签、排序、筛选

**分类页签（第一行）**：待我处理 / 优先处理 / 我已处理 / 星标 —— 右侧数字是条数。

**三个入口（第二行）**：

- **全部类型**：按四种时间语义筛（只看「活动」或只看「截止」）
- **排序**：创建时间 / 截止时间等
- **筛选**：优先级、完成状态、时间范围

**标签（第三行）**：

- **标签管理**：新建、删除、**拖动排序**、给每个标签**配色（10 色盘）**
- 点标签即筛选，多选是「与」的关系；再点一次取消
- 选中的标签会出现在「清除标签筛选」按钮上

> **标签什么时候才会出现？**
> 只有你在「标签管理」里**点「添加」新建**之后才会出现在标签库里（以及筛选行里）。
> 在待办上随手填一个标签，它只属于那条待办，不会污染标签库。
> 这是刻意设计的：标签库应该只放你正式登记的分类。

## 四、提醒与闹钟

**设置 → 待办提醒方式**，两种选一种：

| 方式 | 表现 | 适合 |
|---|---|---|
| **通知** | 横幅弹出 + 响铃，带「延迟提醒 / 划掉」 | 日常 |
| **闹钟** | **全屏**提醒 + 循环播放系统闹钟铃声 + 震动，可延迟 10 分钟或划掉 | 必须叫醒你的事 |

**闹钟配色**：四套预设（天依蓝 `#66CCFF` / 爱莉粉 / 清新绿 / 静谧紫），
浅色 + 毛玻璃，设置里可以**预览真实页面**再决定。

**闹钟可靠性自检**：设置 →「闹钟可靠性」会一项项查
（全屏闹钟授权、锁屏弹出、电池白名单、精确闹钟权限），
哪一项没开它会直接告诉你怎么开。

**默认提醒提前量**：设置 →「默认提醒提前量」（默认 30 分钟）。
新建待办时子步骤留空就用它，改了会影响之后新建的待办。

> 提醒依赖通知权限；精确闹钟需要「闹钟与提醒」权限，被拒绝时会自动降级为不精确调度。

## 五、专注计时

**专注页**（底部第三个标签）：

- 工作 / 休息自动交替，默认 **1 小时工作 / 15 分钟休息**（设置里可改）
- 工作段走完会弹一条通知提醒你起来走走（可在设置里关）
- **专注记录**：今天 / 本周 / 本月的专注时长、最近七天、按任务分布

可以把「开始专注」直接绑在某条待办上（待办详情 →「开始专注」），
于是专注时长会记到那条待办上。

## 六、AI 整理（默认关闭，自带 Key）

**它能做什么**：把一段通知、聊天记录、邮件，甚至**一张截图**，整理成一条结构化待办 ——
标题、描述、类型、时间、地点、标签、子待办一次到位。

**怎么用**：

1. 待办页右上角 `+` → **AI 整理**（或从其它 App 分享文字/图片进来）
2. 贴文字，或选一张/多张截图
3. 等它出草稿 → **逐项确认再保存**（不会直接写进你的数据）

**它特别擅长把"清单"拆出来**：原文写「着装：统一白色院衫、带校徽、带纸巾、雨伞」时，
它会拆成 `穿白色院衫` / `带校徽` / `带纸巾` / `带雨伞` 这几条**清单型子待办**（没有时间，到场前逐条打钩），
而不是把这串东西一股脑塞进描述里。

**开启方式**：设置 → AI 智能助手 → 填你自己的模型 Key（当前支持 DeepSeek）。
默认关闭；开启后待办文本会发送到**你自己配置的**服务商。

## 七、课表：双来源 + 空数据保护

**课表在哪**：日程页（底部第一个标签）→ 右上角**列表图标**切到课表；
再点一次（返回箭头）回到「接下来」或「日历」。

**为什么它比官方版抗折腾**：

| 情况 | 官方版 | Elychron |
|---|---|---|
| 教务在选课/排课期间返回空课表 | 课表变空、课时 0.0 | **自动改用智慧研工（eta）取课表** |
| 两个来源都拿不到 | 旧课表被空数据覆盖，课就"丢了" | **沿用上一次的课表**，不清空 |
| 校历接口挂了 | 假期/考试周标注异常 | 依次回退：同学期缓存 → 本地推算 |
| 开学前打开课表 | 「无学期信息」一片空白 | 显示新学期课表，并提示开学日期 |

**其它**：

- 时钟图标 = 「接下来」⇄「日历」翻转；列表图标 = 进课表
- 设置 →「同步到系统日历」可把课表写进手机日历（可选，默认关闭）
- 设置 →「导出为 iCal 文件」导给其它日历 App
- 日历里紫金港教学楼会映射成更详细的地址

### 课表拿不到数据怎么办

1. 先在日程页下拉刷新一次（或杀掉 App 重开）
2. 还是空 → 设置 → **诊断与测试** → 看「课表」那一行的数字：
   - `接口返回 0 行` → 学校侧没给数据（选课期间常见），Elychron 会沿用旧课表
   - `接口返回 N 行，解析入库 0 条` → 是解析问题，请把日志发给我们
   - `其中 N 条来自智慧研工` → 兜底生效，数据是好的

## 八、诊断与测试（出问题时的第一站）

**设置 → 诊断与测试**，两种模式：

- **易读报告**：每次刷新的结论（成功几个、降级几个、失败几个）、
  **每个模块的状态**（含「接口返回几行 / 解析入库几条 / 能显示几条」这类数字）、关键时间线、发现的问题
- **原始日志**：完整的技术字段（URL、状态码、耗时、异常类型）

**导出并分享 TXT**：一键导出**脱敏**日志（自动隐藏密码、Cookie、Session、ticket、学号），
报 bug 时把它发出来就行，比截图有用得多。

## 九、分享进来即新建

在微信 / QQ / 浏览器里选「分享」→ Elychron，文字、图片、文件都能直接变成一条待办
（附件会被复制到应用私有目录）。图片可以顺势走 AI 整理。

## 十一、备份与恢复

见 [MIGRATION.md](MIGRATION.md) 第四节。要点：

- 卸载 / 换机 / 升级前**先导出**（数据在应用私有目录，卸载即删）
- 导入是**合并**而非覆盖：按 `uid` 比更新时间，删除留墓碑
