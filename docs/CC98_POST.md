# 【开源更新】Celechron 的超级升级版 Elychron 今天起正式发布，在课表查询稳定性、日程设置实用性上有显著提升

> 感谢 Celechron 原作者以及众多协作者的杰出工作！Elychron 是基于 Celechron 的衍生项目，由 Tixer 维护。

> Elychron 不是 Celechron 官方版本，与官方项目无关。

## 一、开发缘由

Celechron 是一款面向浙大学生的开源时间管理工具，可以查看课表、成绩、考试、作业等信息，同时允许学生自定义日程以便于规划学习生活。

在 v1.3 版本更新后，查看课表等数据不稳定的问题已经得到了大幅缓解，但是面对本科教务网失效、被神秘力量阻止访问等情况依旧无法及时查看课表，导致众多小白规划受到影响。同时，实用性较弱的 DDL＆日程功能无法与市面成熟工具（系统日历、钉钉等）相提并论，日常使用便捷性不足，导致其处于一个比较尴尬的境地。

针对此类痛点，我针对性地大规模重写了日程功能，统一并细分了四种时间语义，接入了大语言模型，优化了提醒功能的实现，增设子待办细化任务流程，增设专注模式便于统计，增设备用课务数据来源，增设缓存备份机制，增强软件整体鲁棒性，打磨整体使用手感，最终以这一版差强人意的 Elychron 为名独立发行。

因为 Elychron 与原版 Celechron 差异巨大，已经不适合作为社区版本发布（否则易导致混淆和版本混乱，合并代码工作量巨大），因此选择独立发行（绝对不是因为我有私货）。

## 二、更新内容

### 1. 已有功能优化

- 为课表数据增设缓存功能（issue #174），使之能够在完全脱离网络连接的情况下依然可以查看课表
- 增设 eta 获取数据渠道（issue #174），确保本科教务网不可用期间（譬如选课）也可以正常获得数据
- **空数据不再覆盖缓存**：教务明确返回空课表时不再把它写进缓存，而是沿用上一次成功解析的课表。以前的表现是「刷新一下课表全没了、课时变 0」，现在不会了
- **校历多级回退**：远程配置 → 同学期缓存 → 本地推算，上游校历接口挂掉时只影响假期与考试周标注，课表照常显示
- **开学前也能看课表**：学期还没开始时直接显示新学期课表并提示开学日期，不再是干巴巴一句「无学期信息」
- **课表页布局修正**：课表网格高度改为按屏幕实际可用高度计算（原先写死 560），不再被底部标签栏挡掉半截
- **系统日历里的名字改成「Elychron 课表」**：以前叫「Celechron 课表」，会让人误以为装的是官方版。升级上来的同学原来那份日历会被自动认领改名，不会出现两份课表日历
- **诊断与测试更有用**：刷新结果会写明「接口返回几行 / 解析入库几条 / 能显示几条」，出问题不用猜；一键导出**脱敏**日志，密码、Cookie、学号都会自动隐藏
- **更新提醒分轻重**：小版本更新只提醒一次，不再天天弹；主版本号变化则强制更新，避免老版本带着已知问题继续用

### 2. 新增功能

**待办：四种时间语义 + 子待办行程表**

- 把原来笼统的「任务/DDL」拆成**活动 / 截止 / 提醒 / 备忘**四种时间语义，各自的提醒锚点、逾期判定、日历表现都不同。比如「9 点开始考试」锚在开始前 30 分钟，「9 点前交作业」锚在截止前，而「记得买牙膏」这种备忘型永不提醒、永不逾期
- **子待办不只是勾选清单**：每一步都能带自己的开始/结束时间与提前提醒，等于把一件大事排成一张行程表；也能只当打钩项用（「带雨伞」「穿白色院衫」这类清单项不带时间）
- 待办列表直接显示「下一步 17:45 到紫云篮球场集合」，不用点进去看

**待办页：钉钉风格的重做**

- 分类页签：待我处理 / 优先处理 / 我已处理 / 星标
- 标签体系：标签管理里可新建、删除、**拖动排序**、**每个标签单独配色**（10 色盘）；标签筛选可多选
- 标签库只在你**真正新建**时增加 —— 随手在待办上填的标签只属于那条待办，不会污染标签库
- 支持多条件筛选、排序、周期性待办完成后自动生成下一次

**提醒与闹钟**

- 提醒方式二选一：**通知**（横幅 + 响铃，带延迟/划掉）或**全屏闹钟**（全屏弹出 + 循环播放系统闹钟铃声 + 震动，可延迟 10 分钟或划掉）
- 四套闹钟配色预设（天依蓝 / 爱莉粉 / 清新绿 / 静谧紫），可在设置里预览真实页面
- 新增「**闹钟可靠性**」自检页：全屏闹钟授权、通知渠道重要度、电池优化白名单一项项查，哪项没开直接给你跳转按钮（国产 ROM 杀后台是闹钟不响的头号原因）
- 关键事项还可以**直接交给系统时钟**：待办详情 → ⋯ →「设为系统闹钟」，优先级等同你的起床闹钟。注意系统闹钟是一次性的，而且**不会随待办完成/删除而撤销**，要改要删得自己去「时钟」应用操作 —— 所以它只做手动入口

**专注模式**

- 工作 / 休息自动交替（默认 1 小时 / 15 分钟，可改），工作段走完弹通知提醒你起来走走
- 专注记录：今天 / 本周 / 本月时长、最近七天趋势、按任务分布

**AI 整理（默认关闭，自带 Key）**

- 把一段通知、聊天记录、邮件，甚至**一张截图**，整理成一条结构化待办：标题、描述、类型、时间、地点、标签、子待办一次到位
- 它特别擅长把清单拆出来：原文写「着装：白色院衫、带校徽、带纸巾、雨伞」，会拆成「穿白色院衫」「带校徽」「带纸巾」「带雨伞」几条清单型子待办，而不是把这串字塞进描述里
- 默认关闭；开启需要填自己的模型服务商 Key（当前支持 DeepSeek），内容只发给你自己配置的服务商

**其它**

- 其它应用分享图片/文件/文字进来即可新建待办
- 待办 **JSON 导出 / 导入**：按 uid + 更新时间合并（不是覆盖），删除留墓碑，所以「在一台设备删了，导入后不会又冒出来」
- 全应用文案「任务」统一为「待办」

## 三、安装与数据

**下载**：GitHub Release（只提供 arm64 包，近年的校园机型都支持）

https://github.com/Elyyyyyyyyxer/Elychron/releases/latest

- 与官方 Celechron **包名不同，可以共存**（`xyz.nosig.celechron.mod` vs `xyz.nosig.celechron`），装它不会覆盖官方版，数据也互不影响
- 首次安装需要在系统里允许「安装未知来源应用」
- 校验：APK 的 SHA-256 与签名指纹都写在 Release 说明里，对不上就不是本项目的包

**从官方版迁过来**：课表、成绩、考试、作业、素质拓展、校园卡这些**登录同一个学校账号就有**，不用搬。真正要手动处理的只有你自己手写的待办 —— 官方版没有数据导出功能，所以这部分得重建；重建太慢的话可以用 AI 整理的**截图识别**批量补（一次读一屏）。

**升级提醒**：如果你装过早期的魔改版（同样是 `xyz.nosig.celechron.mod`），本次签名有变化，**覆盖安装会失败**。请先「设置 → 数据 → 导出数据」，再卸载旧版、装新版、导入回来。无论何时，卸载前导出都是个好习惯（数据在应用私有目录，卸载即删，没有回收站）。

## 四、已知问题

- 只提供 arm64 包
- **局域网直连网页端**（手机当服务器、电脑浏览器操作待办）**尚未开放**，本版设置里没有入口，做完会开
- **跨网络同步（坚果云 / WebDAV）只有预留配置项，功能未实现**
- 校历配置仍依赖上游的公开只读接口，挂了会回退到缓存 / 本地推算，只影响假期与考试周标注
- AI 功能需要自备模型服务商的 Key

## 五、反馈

- 问题与建议请提到 [GitHub Issues](https://github.com/Elyyyyyyyyxer/Elychron/issues)（论坛帖子容易沉，Issue 不会丢）
- 报问题时请附上 **设置 → 诊断与测试 → 导出并分享 TXT** 的日志，它已经自动脱敏（密码、Cookie、学号都不会带出去），比截图有用得多

**Elychron 没有自己的服务器，不收集任何上传任何数据。** 会联网的场景只有：拉取你自己的教务数据、课表兜底来源、只读的公开校历接口、检查更新，以及你主动开启的 AI。逐条说明见仓库里的 `PRIVACY.md`。
