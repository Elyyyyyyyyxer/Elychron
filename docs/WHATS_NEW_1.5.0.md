# Elychron 1.5.0（2026-09-30）

> 版本号：1.5.0-elychron.1+11（pubspec.yaml 与 lib/worker/fuse.dart 两处必须一致，
> 有单测 test/version_consistency_test.dart 钉着）。
> 按用户要求：**不改 releases、不发布**，只改版本号。

## 这一版做了什么（按时间倒序）

### 通知（踩坑最多的一块）

- 「首次成绩推送已开启」原来挂在**后台任务**里（WorkManager 每 15 分钟一次），
  靠加密存储判断"说过了"——而后台 isolate 读加密存储不一定成功，记录一丢就重发。
  用户原话：「一天会给我推送很多次那个通知」。现在开场白只在**前台**说一次，
  并改用**文件**记账（lib/worker/notification_dedup.dart）；后台只发真正的新消息。
- **提醒静默不响**：上课/待办提醒走精确闹钟，而精确闹钟权限原来是靠设置里
  「闹钟可靠性」那一页申请的——删掉自带闹钟时把那一页一起下线了，
  于是重装后提醒**静默失败**（异常被吞）。现在启动主动申请（ensureReminderPermission）。
- 「成绩推送」不再占通知 id 0（改成 90001），免得顶掉别的通知。

### 专注

- **杀后台/被冻结后回来，静默接回专注**：记录状态（工作/休息/暂停）→ 回来后按墙上时钟
  **逐段推进**（advanceFocusAnchor，纯函数 + 单测）→ 直接进专注页继续跑（autoContinue），
  不问用户；暂停态按用户拍板的 (a) 保持暂停。
- 两个钩子：冷启动 1.2 秒后，以及**从后台回到前台**（EMUI 的"杀后台"常是冻结，
  进程没死、main() 不会再跑）。
- 停太久的暂停（>12 小时）自动结算，**时长照记**（原来那段时长永远进不了统计）。

### 同步（WebDAV 全平台）

- **课程资料在两台设备上互相翻倍**（真机截图一张图出现 4 次）：
  mergeCourseMounts 按**本地路径**去重，而路径是每台设备自己的（下载落盘名带本机时间戳）
  → 改成按**名字 + 大小**（跨设备身份）去重；"删资料"的墓碑也按身份再记一份。
  顺带解释了当月下载流量 84 → 148 MB 的异常增长。
- **循环待办的"下一次"两台各长一条**（用户："电脑端有两个洗头"）：
  spawnNextOccurrences 用本机随机 uid，合并按 uid 取并集 → 现在按「来源 uid + 到期时间」折叠。
- **坚果云 503** 查清是**限流**（社区里 remotely-save 那批插件同坑）：503 讲人话 + 30 分钟自动退避。

### 界面

- 手机端**去掉了分组灰**：设置及其所有子页面、学业子页面、待办编辑/新建、搜索页
  统一白色（实测取样：日程页 #FDFDFE、设置页 #F2F2F7 → 现在都是 #FFFFFF）。
- 电脑端：左上角换成**爱莉**图标；导航项恢复功能图标；
  字体换成 **HarmonyOS Sans SC**（装在 Windows 用户字体目录，不塞进包），字距 0.5。
- 待办页支持**下拉刷新**（= 立刻跨设备同步一次 + 重读本地待办）。

### 其它

- **删掉「Elychron 自带闹钟」**（全屏响铃那一套 + 闹钟配色/可靠性两页 + 5 个文件，共 -953 行）；
  提醒方式恒定"通知"；**「同步到系统闹钟」一行没动**。
- 启动不再等网络：自动重登从 runApp 之前挪到之后（真机冷启动实测 542~999ms）。
