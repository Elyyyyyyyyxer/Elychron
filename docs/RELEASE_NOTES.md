## 本版（1.4.1）新增

- **课程挂载**：点开一门课，能看到挂在它下面的**资料 / 评论 / 待办**；
  待办可以「挂到某门课」，专注记录与统计也能按课程归属（设置里可关）
- **专注按课程统计**：统计页新增「本月按课程」；专注开始时按**开始时刻的那一节课**
  自动记下课程（可关），不想要就关掉
- **国内也能收到更新了**：更新检查原来是只读 GitHub 的，而国内常常连不上 → 现在按
  **GitHub → Gitee** 的顺序尝试，谁先回应就用谁；**「去下载」会打开实际回应的那个源**，
  不会再出现「提示有新版本却打不开下载页」
- **一键「复制反馈信息」**：设置 → 数据 → 复制反馈信息，一次把
  **机型 / 系统版本 / App 版本 + 最近 120 行脱敏日志 + 反馈模板**复制到剪贴板，
  直接粘到 QQ 群或论坛帖即可报问题（日志里的密码、Cookie、学号已自动隐藏）
- **iCal（.ics）导入**：把别的日历 / 课表导出的 .ics 导入成待办，按 iCal 自带的
  `UID` 去重，重复导入不会产生重复待办
- **分享到「已有待办」**：从别的应用分享文字/图片时，除了新建，还可以追加成
  某条已有待办的附件与描述
- **专注时自动免打扰**（可关）：专注段静音、**休息段自动还原**（休息时能收到消息），
  离开专注页或 App 被杀后都会把系统档位还原
- **批量编辑待办**：待办页 ⋯ → 批量编辑，可多选批量完成 / 删除
- **专注可以"暂停着离开"**：暂停后直接返回不会结束这次专注，去改待办、回消息都行；
  「专注」页会出现「有一次专注还没结束」，点「继续」原样接着做（剩余时间、已专注时长都接回去）
- **AI 生成待办带课程**：只有原文**明确提到课程**时才挂到那门课上；课表里找不到会提示
- **AI 拆子待办最多 7 条**（原来是 5 条）
- **登录：账号密码永远能预填**：换设备/重装/系统"失忆"都不怕 —— 账号同时镜像进数据库；
  「退出登录」只清登录态，不会把你自己愿意记住的账号一起清掉
- **登录态失效如实显示**：真失效才提示，并给一键重登；单个子站自己的登录问题
  不再冒充「你登录失效了」
- **使用教程**：设置 → 教程，三分钟走一遍主要功能
- **待办页多种「进行中」同屏**：「接下来」页面同时有多件事在进行时，
  顶层一张大卡、其余像**一叠卡片**叠在下面；点那叠卡的边会弹出列表，选一条放到顶层
- **日程页上滑收起日历**：上滑折成一行（星期 + 日期 + 小圆点标记），
  回到顶部下拉展开；日历下方的小提示（— / ⌄）点一下、划一下都能折叠/展开
- **课后/课前提醒提前量**：前面没课时提前 30 分钟、连着上课时提前 10 分钟

### 本版修复

- **点「成绩」卡片整个 App 卡死（重要）**：一门成绩都还没有时，成绩页会在空列表上取下标
  （越界报错），而 GetX 的错误路径会把整个界面拖进死循环 —— 表现是**点什么都没反应、
  半分钟后系统弹「Elychron 无响应」**。现在没有成绩就显示「还没有成绩」，
  并且给全局错误处理加了一道保险，任何一处界面出错都不会再把 App 拖死
- **从成绩卡片点进「课程详情」可能打不开**：军训、体育、通识课这些**没排进课表**的课照样有成绩，
  以前点进去会直接报错；现在会明说「课表里没有这门课」
- **闹钟关掉后一直重复弹**（重要）：根因是"弹窗一关就把去重记录清空"，
  于是同一分钟内会反复弹。现在按「提醒时刻」去重，关掉、重启 App 都不会再弹
- **横幅通知上的「划掉」点了没反应**：那个按钮原来声明成"纯后台动作"，
  响应只会送到后台进程 —— 通知取消了、**全屏闹钟照样响**。现在它会走前台，
  闹钟页跟着关闭、铃声停止
- **「接下来」的倒计时不再停在旧值**：每 20 秒自动重算，且只在看「接下来」时刷新
- **刷新很卡、要退出重进才能刷好**：真因是"异步刷新"默认关闭（要等全部模块刷完），
  现在默认开启；老用户会被一次性迁移
- **登录不再被单个子站拖垮**：只看统一身份认证；失败/降级的子站会在进入后
  用一句话提示「部分模块暂不可用」，之后下拉刷新自动重试
- **「老是显示登录已失效」的误报**：判据只看统一身份认证的失败，不再把
  单个子站自己的会话提示当成用户登录失效
- **有子待办的待办右滑滑不动**：完成前要先弹确认框，而那个回调正好在抬手那一刻，
  弹框刚出现就被同一次抬手关掉了 —— 现在改成先让卡片弹回、下一帧再走确认流程
- **课程/考试信息弹层重做**：原来是个 iOS 风格 ActionSheet，里面还塞了一条
  与上面重复、算出来可能是空串的「日期关系」项（显示成一块空白选项）。
  现在与 App 其它弹层同一套观感
- **日历横向翻页太灵敏**：原来手指一带就翻月、还可能一口气翻好几页 ——
  现在要划够约 1/4 屏宽才翻
- **课表半学期归属**：研究生/自定义重复那条路径上，"只有冬学期的课"不再跑到秋学期
- **界面报错"一长串非常吓人"**：错误提示改成一句人话 + 可展开的细节
- **闹钟页动画卡顿**：毛玻璃层与每秒变化的内容拆开，模糊只算一次
- **学业页整页空白 + 每 20 秒弹一次错误**（严重）：判据里有个空断言，在
  「已登录但学号读不到」时会崩；现已改成判空，**半坏的登录态本身也一并修掉**
- **活动和日程类待办也能右滑完成 / 右滑恢复**：原先只有「截止」类能滑
- **课程详情、考试详情等子页面底部被系统导航栏遮住**：底部统一留出安全内衬
- **数据安全加固**：盒子文件一旦损坏，**先整份留档（.damaged-时间戳）再重建，绝不静默清空**；
  开机若发现「上次卡在某个盒子上」，这次会先把它挪走再打开 ——
  底线是**App 一定打得开、数据一定留得住**

## 一、已有功能优化

- **增设 eta 备用课表来源（issue #174）**：本科教务不可用期间（譬如选课），
  自动改用**智慧研工**取课表，确保仍能正常拿到数据
- **空数据不再覆盖缓存（issue #174）**：教务明确返回空课表时不再把它写进缓存，
  而是沿用上一次成功解析的课表
- **校历多级回退**：远程配置 → 同学期缓存 → 本地推算；上游校历接口挂掉时只影响
  假期与考试周标注，课表照常显示
- **开学前也能看课表**：学期还没开始时直接显示新学期课表并提示开学日期
- **诊断与测试更有用**：刷新结果会写明「接口返回几行 / 解析入库几条 / 能显示几条」；
  一键导出**脱敏**日志
- **重写时间设置模块**：可按日历选日期，并支持更复杂的重复逻辑
  （新增「每周工作日，跳过双休日」等）
- **课表页不再被底部栏挡住**：网格高度按屏幕可用高度计算，不再是写死的数值；
  切到课表时顶部居中的小圆也不再压在标题上

## 二、新增功能

### 待办：四种时间语义 + 子待办行程表

- **时间语义细化**：统一为「待办」后细分为 **活动 / 截止 / 提醒 / 备忘**，
  各自的提醒时间、逾期判定、日历表现都不同：
  活动 = 完整起止时间（等效原版「日程」）；截止 = 只有截止时刻（等效原版「DDL」）；
  提醒 = 只有一个提醒时刻；备忘 = 无时间无提醒，当备忘录用
- **新增子待办**：分为**清单类**（无时间，默认提前显示）与**日程类**（有起止时间，
  可自动排序成日程表）
- **新增附件 / 优先级 / 标签**：可挂附件、优先级参与分类、标签库便于批量整理
- **新增评论**：长程任务里记录实时情况
- **新增待办页筛选器**：按时间语义、创建时间、标签等筛选
- **删除增加二次确认**
- **合并「接下来」与「日程」**：顶部圆形按键翻页切换，默认打开「接下来」

### AI 整理（默认关闭，自带 Key）

- **全自动日程转换**：通知、聊天记录、邮件甚至**一张截图** → 结构化待办
  （标题、描述、类型、时间、地点、标签、子待办一次到位）
- **自动拆解子待办**：「着装：白色院衫、带校徽、带雨伞」会拆成若干**清单类**子待办，
  行程时间则写成**日程类**子待办
- **默认关闭**：开启需填自己的模型服务商 Key（当前仅支持 DeepSeek），
  内容只发给你自己配置的服务商

### 待办页：钉钉风格的重做

- **分类页签**：待我处理 / 优先处理 / 我已处理 / 星标
- **标签体系**：可新建、删除、**拖动排序**、**每个标签单独配色**（10 色盘）；筛选可多选

### 提醒与闹钟

- **提醒方式可选**：**通知**（横幅 + 响铃）或**全屏闹钟**
  （全屏弹出 + 循环系统闹钟铃声 + 震动，可延迟 10 分钟或划掉）
- **四套闹钟配色预设**（天依蓝 / 爱莉粉 / 清新绿 / 静谧紫）
- **闹钟可靠性自检页**：全屏闹钟授权、通知渠道重要度、电池优化白名单检查，
  没开的可一键跳转设置
- **可选系统时钟提醒**：待办详情 → ⋯ → 设为系统闹钟。
  ⚠️ 系统闹钟**一次性**、且**不会随待办完成 / 删除而撤销**，要改要删得自己去「时钟」应用操作

### 专注模式

- **新增专注页**：工作 / 休息循环，可指定待办，也可自由新建临时任务专注
- **工作 / 休息自动交替**（默认 1 小时 / 15 分钟，可改）
- **专注记录**：今天 / 本周 / 本月时长、最近七天趋势、按任务分布

### 其它

- **跨应用联动**：其它应用分享图片 / 文件 / 文字进来即可新建待办
- **待办 JSON 导出 / 导入**：按 `uid` + 更新时间合并（不是覆盖），删除留墓碑

## 三、安装与数据

- 与官方 Celechron **包名不同，可以共存**，装它不会覆盖官方版，数据互不影响
- **从官方版迁过来**：课表、成绩、考试、作业、素质拓展、校园卡
  **登录同一个学校账号就有**，不用搬；只有你自己手写的待办需要在待办页截屏后用 AI 整理重建

## 四、已知问题

- 只提供 arm64 包
- **桌面小组件「最近待办」（PR #4，[@LisirX](https://github.com/LisirX) 贡献）本版暂未开放**：
  代码已经合并进仓库，但它的刷新依赖系统后台调度 —— 在系统的「电池优化」限制下会出现
  "点了勾选，小组件画面不刷新"（进一下 App 就正常）。与其发一个时灵时不灵的功能，
  不如等有解再开。**本版里它的入口是关闭的**，桌面小组件列表中不会出现它
- **局域网直连网页端尚未开放**，为后续开发目标，当前版本不可使用
- 跨网络同步（坚果云 / WebDAV）只有预留配置项，功能未实现
- 校历配置仍依赖上游的公开只读接口，挂了会回退到缓存 / 本地推算
- AI 功能需要自备模型服务商的 Key

## 五、反馈

- 问题与建议请提到 [GitHub Issues](https://github.com/Elyyyyyyyyxer/Elychron/issues)
  或 [Gitee Issues](https://gitee.com/P3RF3CT/elychron/issues)

  里面已经有你的机型、系统、版本与**已脱敏**的日志，比截图有用得多

**Elychron 没有自己的服务器，不收集、不上传任何数据。**
会联网的场景只有：拉取你自己的教务数据、课表兜底来源、只读的公开校历接口、检查更新，
以及你主动开启的 AI。
