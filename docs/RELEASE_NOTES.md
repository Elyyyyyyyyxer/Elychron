## 本版（1.4.1）新增

- **国内也能收到更新了**：更新检查原来是只读 GitHub 的，而国内常常连不上 → 现在按
  **GitHub → Gitee** 的顺序尝试，谁先回应就用谁；**「去下载」会打开实际回应的那个源**，
  不会再出现「提示有新版本却打不开下载页」
- **一键「复制反馈信息」**：设置 → 数据 → 复制反馈信息，一次把
  **机型 / 系统版本 / App 版本 + 最近 120 行脱敏日志 + 反馈模板**复制到剪贴板，
  直接粘到 QQ 群或论坛帖即可报问题（日志里的密码、Cookie、学号已自动隐藏）

### 本版修复

- **「接下来」的倒计时不再停在旧值**：卡片上的「还有 N 分钟」以前只在页面碰巧重建时
  才重算一次，实测出现过状态栏 13:16 而卡片还写着「还有 24 分钟」（13:01 的旧值）。
  现在每 20 秒自动重算，且只在看「接下来」时刷新
- **课程/考试信息弹层重做**：原来是个 iOS 风格 ActionSheet，里面还塞了一条显示日期关系的
  项 —— 既与上面的信息重复、算出来还可能是空串，于是显示成一块「莫名其妙的空白选项」。
  现在改成与 App 其它弹层同一套观感（大字标题 + 带图标的信息行 + 粉色主按钮）
- **登录不再被单个子站拖垮**：以前判据是「所有子站都登录成功才算成功」，
  所以教务网（zdbk）故障时哪怕统一身份认证已经通过、其它模块都能用，用户也**进不去 App**。
  现在**只看统一身份认证**：身份通过即视为登录成功，失败/降级的子站会在进入后
  用一句话提示「部分模块暂不可用」，之后下拉刷新会自动重试

> 1.4.0 的全部改动同样包含在本版中，见下方逐条说明。

## 一、已有功能优化

- **增设 eta 备用课表来源（issue #174）**：本科教务不可用期间（譬如选课），
  自动改用**智慧研工**取课表，确保仍能正常拿到数据
- **空数据不再覆盖缓存（issue #174）**：教务明确返回空课表时不再把它写进缓存，
  而是沿用上一次成功解析的课表
- **校历多级回退**：远程配置 → 同学期缓存 → 本地推算；上游校历接口挂掉时只影响
  假期与考试周标注，课表照常显示
- **开学前也能看课表**：学期还没开始时直接显示新学期课表并提示开学日期
- **诊断与测试更有用**：刷新结果会写明「接口返回几行 / 解析入库几条 / 能显示几条」；
  一键导出**脱敏**日志
- **重写时间设置模块**：可按日历选日期，并支持更复杂的重复逻辑
  （新增「每周工作日，跳过双休日」等）
- **课表页不再被底部栏挡住**：网格高度按屏幕可用高度计算，不再是写死的数值；
  切到课表时顶部居中的小圆也不再压在标题上

## 二、新增功能

### 待办：四种时间语义 + 子待办行程表

- **时间语义细化**：统一为「待办」后细分为 **活动 / 截止 / 提醒 / 备忘**，
  各自的提醒时间、逾期判定、日历表现都不同：
  活动 = 完整起止时间（等效原版「日程」）；截止 = 只有截止时刻（等效原版「DDL」）；
  提醒 = 只有一个提醒时刻；备忘 = 无时间无提醒，当备忘录用
- **新增子待办**：分为**清单类**（无时间，默认提前显示）与**日程类**（有起止时间，
  可自动排序成日程表）
- **新增附件 / 优先级 / 标签**：可挂附件、优先级参与分类、标签库便于批量整理
- **新增评论**：长程任务里记录实时情况
- **新增待办页筛选器**：按时间语义、创建时间、标签等筛选
- **删除增加二次确认**
- **合并「接下来」与「日程」**：顶部圆形按键翻页切换，默认打开「接下来」

### AI 整理（默认关闭，自带 Key）

- **全自动日程转换**：通知、聊天记录、邮件甚至**一张截图** → 结构化待办
  （标题、描述、类型、时间、地点、标签、子待办一次到位）
- **自动拆解子待办**：「着装：白色院衫、带校徽、带雨伞」会拆成若干**清单类**子待办，
  行程时间则写成**日程类**子待办
- **默认关闭**：开启需填自己的模型服务商 Key（当前仅支持 DeepSeek），
  内容只发给你自己配置的服务商

### 待办页：钉钉风格的重做

- **分类页签**：待我处理 / 优先处理 / 我已处理 / 星标
- **标签体系**：可新建、删除、**拖动排序**、**每个标签单独配色**（10 色盘）；筛选可多选

### 提醒与闹钟

- **提醒方式可选**：**通知**（横幅 + 响铃）或**全屏闹钟**
  （全屏弹出 + 循环系统闹钟铃声 + 震动，可延迟 10 分钟或划掉）
- **四套闹钟配色预设**（天依蓝 / 爱莉粉 / 清新绿 / 静谧紫）
- **闹钟可靠性自检页**：全屏闹钟授权、通知渠道重要度、电池优化白名单检查，
  没开的可一键跳转设置
- **可选系统时钟提醒**：待办详情 → ⋯ → 设为系统闹钟。
  ⚠️ 系统闹钟**一次性**、且**不会随待办完成 / 删除而撤销**，要改要删得自己去「时钟」应用操作

### 专注模式

- **新增专注页**：工作 / 休息循环，可指定待办，也可自由新建临时任务专注
- **工作 / 休息自动交替**（默认 1 小时 / 15 分钟，可改）
- **专注记录**：今天 / 本周 / 本月时长、最近七天趋势、按任务分布

### 其它

- **跨应用联动**：其它应用分享图片 / 文件 / 文字进来即可新建待办
- **待办 JSON 导出 / 导入**：按 `uid` + 更新时间合并（不是覆盖），删除留墓碑

## 三、安装与数据

- 与官方 Celechron **包名不同，可以共存**，装它不会覆盖官方版，数据互不影响
- **从官方版迁过来**：课表、成绩、考试、作业、素质拓展、校园卡
  **登录同一个学校账号就有**，不用搬；只有你自己手写的待办需要在待办页截屏后用 AI 整理重建
- 备份与恢复细节见仓库里的 `docs/MIGRATION.md`

## 四、已知问题

- 只提供 arm64 包
- **局域网直连网页端尚未开放**，为后续开发目标，当前版本不可使用
- 跨网络同步（坚果云 / WebDAV）只有预留配置项，功能未实现
- 校历配置仍依赖上游的公开只读接口，挂了会回退到缓存 / 本地推算
- AI 功能需要自备模型服务商的 Key
