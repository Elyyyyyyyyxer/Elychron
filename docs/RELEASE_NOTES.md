# Elychron v1.4.0-elychron.1

> Celechron 的**非官方改版**。与官方版**包名不同，可以共存**，装它不会覆盖官方版。
> 基于上游 v1.3.0（commit `ceab2a4`），遵循 GPLv3，源码即本仓库。

## 下载

- `Elychron-v1.4.0-elychron.1-arm64.apk`（只出 arm64，近年的校园机型都支持）
- 校验：`sha256` 见下方
- 首次安装需要在系统里允许「安装未知来源应用」

## 这一版有什么

### 电脑上也能用：局域网直连网页端

手机打开「局域网同步」→ 同一 Wi-Fi 下的电脑浏览器输入手机上显示的 6 位配对码，
就能在电脑上管理同一份待办。**不需要账号、不需要装客户端、数据不经过任何服务器**
（手机自己当服务器，页面是内嵌在 App 里的一份网页，连不上外网也能用）。

- 视觉与手机端同一套语言：爱莉希雅粉 `#FF699A`、iOS 分组背景、跟随系统深色模式
- 宽屏双栏工作台（左栏新建与导入、右栏任务），窄屏自动收成单栏
- 任务与**子待办**都能改：完成状态、开始 / 结束时间、单独提前量
- 提醒弹窗一律钉在**整个屏幕右下角**，最新一条贴着角落
- 断线自动重连；重新配对后**继续刚才没保存完的改动**，不用重打一遍
- 安全：只服务私有网段、token 只走请求头、默认关闭、离开页面即停止监听
  （细节见 [PRIVACY.md](PRIVACY.md)）

### 校内数据更抗折腾

- **课表双来源**：本科教务在选课 / 排课期间会「请求成功但返回空课表」，
  这时自动改用**智慧研工**取课表
- **空数据不清空**：两个来源都拿不到时，**沿用上一次的课表**，不再出现
  「刷新一下课表全没了」
- **校历多级回退**：远程配置 → 同学期缓存 → 本地推算
- **开学前也能看课表**：学期还没开始时显示新学期课表并给出提示，而不是一句「无学期信息」
- **诊断与测试**：内置「易读报告 + 原始日志」，一键导出**脱敏**日志；
  刷新结果会写明「接口返回几行 / 解析入库几条 / 能显示几条」，出问题不用猜

### 时间管理

- **四种时间语义**：活动（时段）/ 截止 / 提醒 / 备忘
- **子待办 = 行程表**：每一步单独的起止时间、完成状态与提前提醒
- **待办**：钉钉风格的新建与详情页、分类页签、标签管理与配色、拖动排序、
  周期性待办自动生成下一次
- **提醒与闹钟**：通知（横幅 + 延迟 / 划掉）或**全屏闹钟**（循环铃声 + 震动 + 延迟 10 分钟）
- **专注计时**：工作 / 休息自动交替，休息结束提醒你起来走走
- **AI 整理**（默认关闭，自带 Key）
- 其它应用**分享进来即新建待办**；待办 **JSON 导出 / 导入**（按 uid + 更新时间合并，删除留墓碑）

## 已知问题

- 只提供 arm64 包
- 「跨网络同步（坚果云 / WebDAV）」**只有预留配置项，功能未实现**
- 校历配置仍依赖上游的公开只读接口 `calendar.celechron.top`；
  它挂掉时会回退到缓存 / 本地推算，只影响假期与考试周标注
- AI 需要自备模型服务商的 Key（当前支持 DeepSeek）

## 数据与隐私

**没有自建服务器，不收集任何数据。** 会联网的场景逐条列在 [PRIVACY.md](PRIVACY.md)：
拉取你自己的教务数据、课表兜底来源、只读公开校历接口、检查更新，
以及你主动开启的 AI 与局域网同步。
