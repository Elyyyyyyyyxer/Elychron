 ## 二、更新内容

 ### 1. 新功能/优化

 **图文教程（App 内置）**

 - **设置 → 使用教程**：内置 6 篇教程，**篇篇带真机截图**，照着做就行。分别是**配置相关**（DeepSeek 密钥怎么申请、闹钟可靠性怎么配、异步刷新、反馈日志在哪）、**基本操作**（待办的三种手势、日历 / 接下来 / 课表怎么切、日历怎么折叠）、**课程相关**、**专注模式**、待办、数据与备份
 - **离线可用、不需要登录**；看过的会自动打勾，长按可以重新观看；**教程里的截图点一下能放大**（还能捏合），再也不用猜按钮在哪

 ![](【待上传：教程中心，6 篇教程的列表页】)

 **课程挂载：资料 / 评论 / 相关待办**

 - 从「日程 → 课表」点一节课，或从「学业 → 课程」点一门课，进详情页就能看到新增的三块：
 - **资料**：课件、笔记、板书照片都能放进来（**文件选择器一并优化过**）；**评论**：课程评分、老师口头交代的事、下次要带什么，随手记；**相关待办**：把作业与材料挂到这门课上，点「新建待办并挂到这门课」直接建
 - **AI 整理时如果提到课程，会自动挂到那门课上**（不提就不挂，避免乱认）

 ![](【待上传：课程详情页，资料 / 评论 / 相关待办三块】)

 **专注模式：暂停可以离开 + 自动免打扰 + 按课程统计**

 - **暂停后可以切到别的页面**（临时想到什么待办直接记），回来说一句「继续」就接着计时，**暂停的时间不计入专注时长**
 - **专注时自动免打扰**，结束或中止时自动恢复（会记住你原来的设置，不会给你改坏）
 - **统计页新增「本月按课程」**：**自由专注只要开始时正在上课，也会算到那门课上**；专注页开始前就写明「本次专注会计入《××》」

 **教务数据：更稳、更少打扰**

 - **校历随包内置**：校历原本来自上游的公开接口（明文 HTTP，实测经常连不上），现在直接把校历 JSON 打进包里 —— **离线可用、首次安装就有**；之后每周才试一次远程更新，有差异就按新的来
 - **被限流能自愈**：教务在「请求太密」时会返回 **HTTP 921**（不是标准 HTTP 码），以前一撞就整块失败落到缓存，现在会退避几秒重试一次
 - **少打教务**：历史学年的课表直接吃缓存（高年级原本一次刷新要查 16 次，现在 0 次）、「已知为空」的学期当天不再重复问、探针学年只探第一个学期，**实测一次刷新少打 4 个请求**
 - **后台刷新改成慢节奏**：后台相邻两个教务请求至少隔 15 秒（前台仍是 300 毫秒），刷得慢一点但不再撞限流；启动刷新也做了节流

 **其它值得一说的**

 - **iCal（.ics）导入**：别的日历导出成 .ics 就能导进来变成待办，**重复导入不会重复**
 - **分享到「已有待办」**：分享进来的内容可以**作为附件与描述追加到某条已有待办**上，长程任务（论文、项目）特别顺手
 - **长按「已登录」看接口通不通**：逐条列出校历 / 课表 / 考试 / 成绩 / 主修 / 作业 / 实践的状态（实时成功（含耗时）/ 走缓存 / 没连上 / 未参与），被教务限流时会直接点名，而且**不额外发请求**
 - **一键「复制反馈信息」**：机型、系统、版本 + **已脱敏**的日志一起进剪贴板，报问题比截图有用得多
 - **退出登录后仍然预填账号密码**；**登录态失效如实显示 + 一键重登**
 - **待办批量编辑**、**课前提醒**、**更新检查（GitHub 不通时走 Gitee 兜底，接受自动更新）**
 - **弹窗全面统一成「钉钉风格」**、主题色统一（为将来的自定义主题色留好接口）、文案精简

 ### 2. 修复的问题

 - ★ **点成绩卡片任意位置就卡死** —— Celechron 时期就有的老 bug：一次空列表取值越界，又正好踩到 GetX 的一个坑，把主线程拖到满载。已修
 - ★ **活动类待办无法右滑完成 / 恢复** —— 已修，双向真机验证过
 - ★ **「接下来」的倒计时停在旧值**（时间静止）—— 已修，现在会跟着时间走
 - ★ **闹钟鬼畜：关掉之后一直重复弹** —— 已修
 - **zdbk 限流时候的故事** —— 教务返回 HTTP 921 时以前会直接落缓存，现在退避重试；再加上历史学年吃缓存、「已知为空」不再重复问、后台放慢节奏，被限流的概率明显下降（详见上面「少打教务」）
 - **登录老是失效** —— 登录判据只看统一身份认证，不再误报；真失效时如实显示并给一键重登
 - **深色模式翻卡片「变白一下再恢复」** —— 已修（翻页的页边没解析动态色）
 - **秋冬半学期课程显示混淆** —— 已定位并修掉：教务的半学期字段读不出来时程序会「按查询季节猜」，两次猜测一合并就成了「两半都上」；现在一边确定一边猜时以确定的为准
 - **刷新很卡、要退出重进才能刷好** —— 已优化
 - **界面报错「一长串非常吓人」** —— 报错文案重做，说人话
 - **学业页整页空白 + 每 20 秒崩一次** —— 已定位并修复
 - **两个子页面底部被系统导航栏遮住** —— 已修
 - **课程 / 考试信息弹层重做** —— 信息更清楚、层级更顺

 ## 三、数据与安装

 **下载**：GitHub Release（只提供 arm64 包）

 https://github.com/Elyyyyyyyyxer/Elychron/releases/latest

 - 与官方 Celechron **包名不同，可以共存**，装它不会覆盖官方版，数据互不影响
 - **从 v1.4.0 升上来直接覆盖安装即可，数据不会丢**（这一版还改了缓存自愈逻辑，就算缓存坏了也能自己修回来）
 - 首次安装需要在系统里允许「安装未知来源应用」
 - 校验：APK 的 SHA-256 与签名指纹都写在 Release 说明里
 - 换手机：设置 → 数据 → 导出数据（JSON），新手机上导入即可；也支持 iCal（.ics）导入

 ## 四、已知问题

 - 只提供 arm64 包
 - **教务限流期间**：短时间内刷新太频繁会被教务限流，这时课表 / 成绩会显示上一次的数据（长按设置页的「已登录」会直接告诉你「被限流了」）
 - **秋冬半学期的极端情况**：如果教务那边课程的半学期字段整条都读不出来，仍然只能按「两半都上」显示 —— 那时候任何自动判断都是猜
 - 校历现在**随包内置**，上游接口挂了也不影响使用；但内置的那份要等发新版本才会更新
 - **桌面小组件（最近待办）仍在打磨**：部分机型会被系统的电池优化限制，出现「点了没反应」
 - **局域网直连网页端尚未开放**，当前版本不可使用；跨网络同步（坚果云 / WebDAV）只有预留配置项，功能未实现
 - AI 功能需要自备模型服务商的 Key（目前仅支持 DeepSeek）
