## 一、这次更新了什么

1.4.0 发布之后，我这边陆陆续续收到了不少反馈。1.4.1 是一次**以"修问题 + 补教程"为主**的更新，但也有几件明显的新东西：

- **App 里现在有图文教程了**：设置 → 使用教程，6 篇带截图的教程，从"配置"到"基本操作""课程""专注"，一篇一个功能
- **课程挂载**：课程页面可以放课件与笔记、随手写点记录，还能把相关待办挂到这门课上
- **专注模式补齐三件事**：专注时自动免打扰、**暂停后可以放心去干别的（回来接着计时）**、统计里可以按课程看专注时长
- **教务数据更稳、更少打扰**：校历随包内置（上游那个站老是连不上）、被教务限流能自愈、不再每次刷新都把教务打一遍
- **一口气修掉一批真问题**：点成绩卡片卡死、活动类待办右滑没反应、"接下来"的倒计时停在旧值、闹钟关掉后反复弹、深色模式翻卡片"变白再恢复"、秋冬半学期课程显示混淆、刷新很卡要退出重进……
- **顺手加的小东西**：iCal（.ics）导入、分享到"已有待办"、长按登录看各接口通不通、一键复制反馈信息

## 二、更新内容

### 1. 新增功能

**图文教程（App 内置）**

- **设置 → 使用教程**：现在有 6 篇教程，**篇篇带真机截图**，照着做就行：
  - **配置相关**：DeepSeek 密钥怎么申请、闹钟可靠性怎么配、异步刷新、反馈日志在哪
  - **基本操作**：待办的三种手势（半划截图照着看，露出底色就是手势认到了）、日历 / 接下来 / 课表怎么切、日历怎么折叠与展开
  - **课程相关 / 专注模式 / 待办 / 数据与备份**
- 教程**离线**、**不需要登录**；看过的会自动打勾，随时可以重看；长按可以"重新观看"
- 教程里的截图**点一下可以放大**（能捏合），不用再猜按钮在哪

**课程挂载：资料 / 评论 / 相关待办**

- 从「日程 → 课表」点一节课，或从「学业 → 课程」点一门课，就进课程详情页
- **资料**：课件、笔记、板书照片都可以放进来（点「添加图片 / 文件」）
- **评论**：课程评分、老师口头交代的事、下次要带什么，随手记
- **相关待办**：把作业和材料挂到这门课上，点「新建待办并挂到这门课」直接建
- 顺带一句：**AI 整理时如果提到课程，会自动挂到那门课上**（不提就不挂，避免乱认）

【待上传：课程详情页截图（资料 / 评论 / 相关待办 三块）】

**专注模式：暂停可以放心离开 + 自动免打扰 + 按课程统计**

- **暂停后可以切到别的页面**，临时想到什么待办可以直接记；回来说一句"继续"就接着计时（暂停的时间不计入专注时长）
- **专注时自动免打扰**：开始专注时自动开免打扰，结束或中止时自动恢复（会记住你原来的设置，不会给你改坏）
- **统计页新增"本月按课程"**：**自由专注只要开始时正在上课，也会算到那门课上**；专注页开始前就会写清楚"本次专注会计入《××》"
- 专注记录每条都会带上课程名，一眼看得出这段算给谁了

【待上传：专注页截图（含"本次专注会计入《××》"那行提示）】

**iCal（.ics）文件导入**

- 别的日历导出成 .ics，可以直接导进来变成待办；**重复导入不会重复**
- 适合把教务、系统日历里的安排一次性搬过来

**分享到「已有待办」**

- 原来分享东西进来只能新建待办；现在可以**作为附件与描述追加到某条已有待办上**
- 长程任务（论文、项目）特别顺手：聊天记录、文件、截图可以陆续挂到同一条上

**长按「已登录」→ 看各接口通不通**

- 设置页**长按**「已登录」那一行（或登录页长按登录按钮），弹出接口连通性面板：
  校历 / 课表 / 考试 / 成绩 / 主修 / 作业 / 实践 逐条状态（实时成功（含耗时）/ 走缓存 / 没连上 / 未参与）
- 被教务限流时会直接点名："这次有 N 个请求被教务限流（HTTP 921）——学校那边让你慢一点，不是 App 坏了"
- 这个面板**不额外发请求**，数据就来自现成的诊断日志

**一键「复制反馈信息」**

- 设置 → 数据 → 复制反馈信息：机型、系统、版本 + **已脱敏**的日志一起进剪贴板，直接粘到群里就行
- 比截图有用得多 —— 报问题请优先用这个

**登录相关的两件小事**

- **退出登录后仍然预填账号密码**（以前退出一次就得重新敲一遍）
- **登录态失效如实显示 + 一键重登**（不再"看着像登录着、其实早就过期了"）

**待办批量编辑**

- 待办页可以对多条待办一次性改类型 / 时间 / 标签，不用一条条点

**课前提醒**

- 课表可以按提前量提醒你下一节在哪（算法里带了课间阈值，不会在上课中间乱响）

### 2. 已有功能优化

**教务数据：更稳、更少打扰**

- **校历随包内置**：校历来自上游的公开接口（明文 HTTP，实测经常连不上），现在直接把校历 JSON 打进包里 —— **离线可用、首次安装就有**；之后**每周**才去试一次远程更新，有差异就按新的来
- **被限流能自愈**：教务在"请求太密"时会返回 **HTTP 921**（不是标准 HTTP 码），以前遇到就整块失败落到缓存，现在会退避几秒重试一次
- **少打教务**：历史学年的课表直接吃缓存（高年级原本一次刷新要查 16 次，现在 0 次）；"已知为空"的学期当天不再重复问；探针学年只探第一个学期 —— 实测一次刷新少打 4 个请求
- **后台刷新改成慢节奏**：后台相邻两个教务请求至少隔 15 秒（前台仍是 300 毫秒），刷得慢一点，但不再撞限流，反正有缓存兜底
- **启动刷新做了节流**：刚更新过就不再刷一次，避免和后台刷新叠在一起把教务打爆

**修复（挑能明显感觉到的说）**

- ★ **点成绩卡片任意位置会卡死** —— 真 bug，已修（一次空列表取值越界，又正好踩到 GetX 的一个坑，把主线程拖到满载）
- ★ **活动类待办无法右滑完成 / 恢复** —— 已修，双向真机验证过
- ★ **"接下来"的倒计时停在旧值** —— 已修（现在会跟着时间走）
- ★ **闹钟关掉后一直重复弹** —— 已修
- **深色模式翻卡片"变白一下再恢复"** —— 已修（翻页的页边没解析动态色）
- **秋冬半学期课程显示混淆** —— 已找到机制并修掉（教务的半学期字段读不出来时会"按查询季节猜"，两次猜测一合并就成了"两半都上"；现在一边确定一边猜时以确定的为准）
- **刷新很卡、要退出重进才能刷好** —— 已优化
- **界面报错"一长串非常吓人"** —— 报错文案重做，说人话
- **学业页整页空白 + 每 20 秒崩一次** —— 已定位并修复
- **"老是显示登录已失效"的误报** —— 已修（登录判据只看统一身份认证）
- **两个子页面底部被系统导航栏遮住** —— 已修
- **课程 / 考试信息弹层重做** —— 信息更清楚，层级更顺

## 四、数据迁移（重要！！！）

**从官方版迁过来**：课表、成绩、考试、作业、素质拓展、校园卡**登录同一个学校账号就有**，不用搬。要手动处理的只有你自己手写的待办 —— 官方版没有数据导出功能，这部分得重建，建议在待办页截屏后选择 AI 生成待办。

**从 1.4.0 升到 1.4.1**：直接把新包装上覆盖即可，不用做任何操作。

**换手机**：设置 → 数据 → 导出数据（JSON），新手机上导入即可；现在也支持 **iCal（.ics）导入**，重复导入不会重复。

## 五、已知问题

- 只提供 arm64 包
- **局域网直连网页端尚未开放**，为后续开发目标，当前版本不可使用
- 跨网络同步（坚果云 / WebDAV）只有预留配置项，功能未实现
- **桌面小组件（最近待办）仍在打磨**：部分机型会被系统的电池优化限制，出现"点了没反应"，正式开放时间待定
- **教务限流期间**：如果短时间内刷新太频繁，教务会返回限流，这时课表 / 成绩会显示上一次的数据（面板里会直接告诉你"被限流了"）
- **秋冬半学期的极端情况**：如果教务那边课程的半学期字段**整条都读不出来**，仍然只能按"两半都上"显示 —— 那时候任何自动判断都是猜
- 校历现在**随包内置**，上游接口挂了也不影响使用；但内置那份要等发新版本才会更新
- AI 功能需要自备模型服务商的 Key（目前仅支持 DeepSeek）
