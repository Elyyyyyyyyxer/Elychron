 ## 一、一个小版本号，Elychron 变强了多少？

 承蒙大家喜爱，Elychron v1.4.0 自发布以来已经获得了全平台2000+的下载量！（夸克与gitee未参与统计）Elychron 真的受宠若惊……当然也收到了很多bug报告……所以我连夜疯狂修bug，结果越修越多，越修越想做优化，于是我们的 v1.4.1 就成了现在这个样子！更稳定，更好用，更适合浙大宝宝体质！

 我们到底修了什么？最突出的是一个 Celechron 时期就有的老bug，没有绩点的 xpy 点击绩点会直接崩溃，现在已经不会了！还包括闹钟鬼畜，时间静止， zdbk 限流时候的故事（不是），登录老是失效等等严重影响体验的问题。

 那么加入了什么呢？包括但不限于教程！教程！教程！（重要的事情说三遍），优化文件选择器，课程可以挂载文件评论，接受自动更新。东西不多，但细节上打磨得更加顺手方便！

 下面是正式的更新报告！

 ## 二、更新内容

 ### 1. 新功能/优化

 **图文教程（App 内置）**

 - **设置 → 使用教程**：内置 6 篇教程，有图！有图！看看自己是不是漏掉了什么神秘小功能 ~ 分别是**配置相关**（DeepSeek 密钥怎么申请、闹钟可靠性怎么配、异步刷新、反馈日志在哪）、**基本操作**（待办的三种手势、日历 / 接下来 / 课表怎么切、日历怎么折叠）、**课程相关**、**专注模式**、待办、数据与备份
 - **离线可用、不需要登录**；看过的会自动打勾，长按可以重新观看；教程里的截图点一下可以放大，再也不用猜按钮在哪

 ![](【待上传：教程中心，6 篇教程的列表页】)

 **课程挂载：资料 / 评论 / 相关待办**

 - 从日程 → 课表点一节课，或从学业 → 课程点一门课，进详情页就能看到新增的三块：
 - **资料**：课件、笔记、板书照片都能放进来（**强化文件选择器！**）；**评论**：课程评分、老师口头交代的事、下次要带什么，随手记；**相关待办**：把作业与材料挂到这门课上，点新建待办并挂到这门课也可以挂上
 - **AI 整理时如果提到课程，会自动挂到那门课上**（不提就不挂，避免乱认）

 ![](【待上传：课程详情页，资料 / 评论 / 相关待办三块】)

 **专注模式：暂停可以离开 + 自动免打扰 + 按课程统计**

 - **暂停后可以切到别的页面**（临时想到什么待办直接记），回来点击继续就接着计时，**暂停的时间不计入专注时长**
 - **专注时自动免打扰！！**，结束或中止时自动恢复（会记住你原来的设置，不会给你改坏）
 - **统计页新增本月按课程**：**自由专注只要开始时正在上课，也会算到那门课上**；专注页开始前就写明「本次专注会计入《××》」

 **教务数据：更稳、更少打扰**

 - **校历随包内置**：校历原本来自上游的公开接口（明文 HTTP，实测经常连不上），现在直接把校历 JSON 打进包里，确保**离线可用、首次安装就有**；之后每周才试一次远程更新，有差异就按新的来
 - **被限流能自愈**：zdbk在请求太密时会返回 **HTTP 921**（我真服了），以前一撞就整块失败落到缓存，现在会退避几秒重试一次
 - **少打教务**：历史学年的课表直接吃缓存（高年级原本一次刷新要查 16 次，现在 0 次）、已知为空的学期当天不再重复问、探针学年只探第一个学期，**实测一次刷新少打 4 个请求**
 - **后台刷新改成慢节奏**：后台相邻两个教务请求至少隔 15 秒（前台仍是 300 毫秒），刷得慢一点但不再撞限流；启动刷新也做了节流

 **其它值得一说的**

 - **iCal（.ics）导入**：别的日历导出成 .ics 就能导进来变成待办，**重复导入不会重复**
 - **分享到「已有待办」**：分享进来的内容可以**作为附件与描述追加到某条已有待办**上，长程任务（论文、项目）特别顺手
 - **长按已登录看接口通不通**：逐条列出校历 / 课表 / 考试 / 成绩 / 主修 / 作业 / 实践的状态（实时成功（含耗时）/ 走缓存 / 没连上 / 未参与），被教务限流时会直接点名，而且**不额外发请求**
 - **一键复制反馈信息**：机型、系统、版本 + **已脱敏**的日志一起进剪贴板，报问题比截图有用得多
 - **退出登录后仍然预填账号密码**；**登录态失效如实显示 + 一键重登**
 - **课程资料能看大图了**：课程详情「资料」里的图片直接显示缩略图，点一下就在应用内全屏看（可以捏合放大，看板书特别方便）；长按任意附件还能**重命名 / 用其它应用打开 / 删除**
 - **第一次打开会先带你逛教程**：没进过教程中心、也没看过任何一篇时，第一次打开会弹一句「先花两分钟看下教程？」，点「去看看」直接进教程中心
 - **待办批量编辑**、**课前提醒**
 - **更新检查更靠得住了**：GitHub、Gitee 和两个国内镜像**一起查，取版本号最大的那个**（以前 GitHub 半通就会挡住 Gitee，现在不会了，接受自动更新）
 - **弹窗全面统一成钉钉风格**、主题色统一（为将来的自定义主题色留好接口）、文案精简

 ### 2. 修复的问题

 - ★ **分享一下，专注就没了？？** ：App 被系统杀掉之后，那条还没结算的专注会话一直躺在库里，下次进专注页就被当成异常结算掉。现在会把它**接住**：专注页显示「有一次专注还没结束」，点继续接着做，时长一点都不丢（真机拿"杀进程"验过）
 - ★ **图片分享进来什么都不弹** ：两个原因，都修了：① Android 13+ 的相册、新版微信 QQ 分享图片时把地址放在 clipData 里，而我们以前只读 EXTRA_STREAM，等于没收到；② 附件读不出来时被悄悄丢掉，连一句话都没有。现在两处都读、去重，读不出来也会明说（比如「对方应用没有把这个文件的读取权限给过来」）
 - **有暂停的专注时点开始专注会强制打断上一次** ：现在会先问一句「继续上一次 / 结束并开始新的 / 取消」，选后者时上一次按正常结束算，不再记一笔"未正常"
 - ★ **点成绩卡片任意位置就卡死！！！** ：Celechron 时期就有的老 bug：一次空列表取值越界，又正好踩到 GetX 的一个坑，把主线程拖到满载。已修
 - ★ **活动类待办无法右滑完成 / 恢复** ：现在可以了
 - ★ **接下来的倒计时停在旧值**（时间静止）：已修，现在会跟着时间走
 - ★ **闹钟鬼畜：关掉之后一直重复弹** ：禁止鬼畜
 - **zdbk 限流时候的故事** ：教务返回 HTTP 921 时以前会直接落缓存，现在退避重试；再加上历史学年吃缓存、已知为空不再重复问、后台放慢节奏，被限流的概率明显下降（详见上面少打教务）
 - **登录老是失效** ：登录判据只看统一身份认证，不再误报；真失效时如实显示并给一键重登
 - **深色模式翻卡片变白一下再恢复** ：已修（翻页的页边没解析动态色）
 - **秋冬半学期课程显示混淆** ：已定位并修复。教务的半学期字段读不出来时程序会按查询季节猜，两次猜测一合并就成了两半都上；现在一边确定一边猜时以确定的为准
 - **刷新很卡、要退出重进才能刷好** ：现在非常快了！
 - **界面报错一长串非常吓人** ：报错文案重做，说人话
 - **学业页整页空白 + 每 20 秒崩一次** ：已定位并修复
 - **两个子页面底部被系统导航栏遮住** ：已修
 - **课程 / 考试信息弹层重做** ：信息更清楚、层级更顺

 ## 三、数据与安装

 **下载**：GitHub Release（只提供 arm64 包）

 https://github.com/Elyyyyyyyyxer/Elychron/releases/latest

 - 与官方 Celechron **包名不同，可以共存**，装它不会覆盖官方版，数据互不影响
 - **从 v1.4.0 升上来直接覆盖安装即可，数据不会丢**（这一版还改了缓存自愈逻辑，就算缓存坏了也能自己修回来）
 - 首次安装需要在系统里允许安装未知来源应用
 - 校验：APK 的 SHA-256 与签名指纹都写在 Release 说明里
 - 换手机：设置 → 数据 → 导出数据（JSON），新手机上导入即可；也支持 iCal（.ics）导入

 ## 四、已知问题

 - 只提供 arm64 包
 - **教务限流期间**：短时间内刷新太频繁会被教务限流，这时课表 / 成绩会显示上一次的数据（长按设置页的已登录会直接告诉你被限流了）
 - **秋冬半学期的极端情况**：如果教务那边课程的半学期字段整条都读不出来，仍然只能按两半都上显示 —— 那时候任何自动判断都是猜
 - 校历现在**随包内置**，上游接口挂了也不影响使用；但内置的那份要等发新版本才会更新
 - **桌面小组件（最近待办）仍在打磨**：部分机型会被系统的电池优化限制，出现点了没反应
 - **局域网直连网页端尚未开放**，当前版本不可使用；跨网络同步（坚果云 / WebDAV）只有预留配置项，功能未实现
 - AI 功能需要自备模型服务商的 Key（目前仅支持 DeepSeek）
