## 它和官方版差在哪

官方版是「查课表 / 查成绩」；Elychron 把重心放在**时间管理本身**，并且自己解决了
校内接口不稳、电脑上看不到待办这两类实际痛点。

### 电脑上也能用：局域网直连网页端

手机上打开「局域网同步」，同一 Wi-Fi 下用**电脑浏览器**就能看待办、改待办、打钩、看提醒 ——
不需要账号、不需要装客户端、**数据不经过任何服务器**（手机自己当服务器，页面就是内嵌在 App 里的一份网页）。

- 视觉与手机端同一套语言：爱莉希雅粉 `#FF699A`、iOS 分组背景、跟随系统深色模式
- 宽屏是双栏工作台（左栏新建与导入、右栏任务），窄屏自动收成单栏
- 提醒弹窗一律钉在**整个屏幕右下角**，最新一条贴着角落
- 配对码换 token、断线自动重连、重新配对后**继续刚才没保存完的改动**
- 详见 [PRIVACY.md](PRIVACY.md) 的「局域网同步会做什么」

### 校内数据更抗折腾

- **课表双来源**：本科教务（zdbk）在选课 / 排课期间会「请求成功但返回空课表」，
  这时自动改用**智慧研工（eta）**取课表；两个来源都没有时，**沿用上一次的课表**而不是清空
- **校历多级回退**：远程配置 → 同学期缓存 → 本地推算，上游接口挂掉也不影响看课表
- **诊断与测试**：内置「易读报告 + 原始日志」，一键导出**脱敏**日志，排查问题不用猜

### 时间管理本身

- **四种时间语义**：活动（时段）/ 截止 / 提醒 / 备忘，各自的提醒锚点与逾期判定都不同
- **子待办 = 行程表**：每一步可单独设开始 / 结束时间、完成状态、提前提醒分钟数
- **待办**：钉钉风格的新建与详情页；分类页签（待我处理 / 优先处理 / 我已处理 / 星标）、
  标签管理与配色、拖动排序、周期性待办完成后自动生成下一次
- **提醒与闹钟**：通知（横幅 + 延迟 / 划掉）或**全屏闹钟**（循环铃声 + 震动 + 延迟 10 分钟）；
  四套闹钟配色预设
- **专注计时**：工作 / 休息自动交替，休息结束会提醒你起来走走
- **AI 整理**（默认关闭）：自带 Key，把一句话拆成结构化待办与步骤
- **分享进来即新建**：其它应用分享图片 / 文件 / 文字都能变待办
- 待办 **JSON 导出 / 导入**，按 `uid + updatedAt` 合并，删除留墓碑，为多端同步打底

## 安装

到 [Releases](https://github.com/Elyyyyyyyyxer/Elychron/releases/latest) 下载 `apk` 直接安装。

- 只提供 **arm64** 包（近年的校园机型都支持）
- 与官方 Celechron **包名不同，可以共存**，数据互不影响
- 首次安装需要在系统里允许「安装未知来源应用」

## 构建

```bash
flutter pub get
flutter build apk --release --target-platform android-arm64 --no-tree-shake-icons
```

> ⚠️ Windows 上**项目路径不能含非 ASCII 字符**（Gradle 会直接拒绝），
> 中文目录下请用 junction / 软链映射到纯英文路径再构建。
> `--no-tree-shake-icons` 是为了绕开 Windows 应用控制策略对 `font-subset.exe` 的拦截。

## 隐私

**没有自建服务器，不收集任何数据。** 会联网的场景只有：拉取你自己的教务数据、
课表兜底来源（智慧研工）、只读的公开校历接口、检查更新，以及你主动开启的 AI 与局域网同步。
逐条说明见 [PRIVACY.md](PRIVACY.md)。
