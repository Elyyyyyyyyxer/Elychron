## 一、为什么会有这个改版

Celechron 可以查课表、成绩、考试、作业，也允许自定义日程。v1.3 之后数据稳定性已经大幅改善，
但仍有两类问题：

1. **教务不可用时课表就没了**：本科教务在选课 / 筛课期间会「请求成功但返回空表」，
   而空结果会覆盖本地缓存 —— 刷新一下课表就空了、课时变 0；
2. **日程功能与成熟工具差距明显**：只有笼统的「任务 / DDL」，没有子任务、标签、优先级、
   专注统计；提醒只有通知一种形式。

于是这个改版做了三件事：**换掉课表数据来源并保住缓存**、**重写整套待办与时间语义**、
**补上提醒、专注、AI 整理这些日常真正会用到的能力**。

因为与原版差异已经很大，不适合作为社区版本合并回上游（会造成版本混乱、合并成本极高），
所以选择独立发行。

## 二、更新内容

### 已有功能优化

- **增设 eta 获取数据渠道（issue #174）**：本科教务不可用期间（譬如选课），自动改用
  **智慧研工**取课表，确保仍能正常拿到数据
- **空数据不再覆盖缓存（issue #174）**：教务明确返回空课表时不再把它写进缓存，
  而是沿用上一次成功解析的课表
- **校历多级回退**：远程配置 → 同学期缓存 → 本地推算；上游校历接口挂掉时只影响
  假期与考试周标注，课表照常显示
- **开学前也能看课表**：学期还没开始时直接显示新学期课表并提示开学日期，
  不再是干巴巴一句「无学期信息」
- **诊断与测试更有用**：刷新结果会写明「接口返回几行 / 解析入库几条 / 能显示几条」，
  出问题不用猜；一键导出**脱敏**日志，密码、Cookie、学号都会自动隐藏
- **重写时间设置模块**：时间设置现在可以打开日程表，按日历选日期；
  同时支持更复杂的重复逻辑（新增「每周工作日，跳过双休日」等），自定义自由度更高

### 新增功能

**待办：四种时间语义 + 子待办行程表**

- **时间语义细化**：把原来笼统的日程 / DDL 统一为「待办」后，再细分为
  **活动 / 截止 / 提醒 / 备忘**四种时间语义，各自的提醒时间、逾期判定、日历表现都不同：
  - **活动**：完整起止时间，提醒默认开始前 30 分钟（等效于原版的「日程」）
  - **截止**：只有截止时刻（等效于原版的「DDL」）
  - **提醒**：只有一个提醒时刻，用于便捷通知
  - **备忘**：无时间、无提醒，充当备忘录
- **新增子待办**：一条待办可以挂多个子待办，分为两类 ——
  **清单类**没有时间、默认提前显示（`带雨伞`、`带校园卡`）；
  **日程类**有起止时间，可自动排序形成日程表
- **新增附件 / 优先级 / 标签**：待办可加附件；优先级参与分类；
  标签库便于批量整理与查看
- **新增评论**：长程任务里记录实时情况，方便数字留痕
- **新增待办页筛选器**：按时间语义、创建时间、标签等筛选，不用疯狂翻页
- **删除增加二次确认**：防止手滑
- **合并「接下来」与「日程」**：屏幕顶部圆形按键翻页切换，默认打开「接下来」

**AI 整理（默认关闭，自带 Key）**

- **全自动日程转换**：把通知、聊天记录、邮件甚至**一张截图**整理成结构化待办 ——
  标题、描述、类型、时间、地点、标签、子待办一次到位
- **自动拆解子待办**：复杂任务拆成可执行步骤；「着装：白色院衫、带校徽、带雨伞」
  会拆成若干**清单类**子待办，行程时间则写成**日程类**子待办
- **默认关闭**：开启需填自己的模型服务商 Key（当前版本仅支持 DeepSeek），
  内容只发给你自己配置的服务商

**待办页：钉钉风格的重做**

- **分类页签**：待我处理 / 优先处理 / 我已处理 / 星标
- **标签体系**：可新建、删除、**拖动排序**、**每个标签单独配色**（10 色盘）；标签筛选可多选

**提醒与闹钟**

- **提醒方式可选**：**通知**（横幅 + 响铃）或**全屏闹钟**
  （全屏弹出 + 循环系统闹钟铃声 + 震动，可延迟 10 分钟或划掉）
- **四套闹钟配色预设**（天依蓝 / 爱莉粉 / 清新绿 / 静谧紫）：设置里可预览真实页面
- **新增闹钟可靠性自检页**：全屏闹钟授权、通知渠道重要度、电池优化白名单检查，
  没开的可以直接跳转设置（国产 ROM 杀后台是闹钟不响的头号原因）
- **可选系统时钟提醒**：重点事项可以**手动**设为系统闹钟
  （待办详情 → 右上角 ⋯ → 设为系统闹钟）。
  ⚠️ 系统闹钟**一次性**、且**不会随待办完成 / 删除而撤销**，要改要删得自己去「时钟」应用操作 ——
  所以它只做手动入口，不做成常驻提醒方式

**专注模式**

- **新增专注页**：进入工作 / 休息循环，可以指定待办，也可以自由新建临时任务进行专注；
  专注页可查看详细统计，用于统计各事务的真实时间消耗
- **工作 / 休息自动交替**（默认 1 小时 / 15 分钟，可改），工作段走完弹通知提醒你起来走走
- **专注记录**：今天 / 本周 / 本月时长、最近七天趋势、按任务分布

**其它**

- **跨应用联动**：其它应用分享图片 / 文件 / 文字进来即可新建待办
- **待办 JSON 导出 / 导入**：按 `uid` + 更新时间合并（不是覆盖），删除留墓碑，便于数据迁移

### 与官方版的对照

| 能力 | 官方 Celechron | Elychron |
|---|---|---|
| **时间语义** | 两种（日程 / DDL） | **四种**：活动 / 截止 / 提醒 / 备忘，各自的提醒锚点、逾期判定、日历表现都不同 |
| **子待办** | ❌ 无 | **清单类 + 日程类**：每步可带起止时间与提前量，也可只做打钩项 |
| **附件 / 优先级 / 标签 / 评论** | ❌ 无 | ✅ 均有（标签库可配色、拖动排序） |
| **专注计时** | ❌ 无 | 工作 / 休息自动交替 + 今日 / 本周 / 本月统计、按任务分布 |
| **AI 整理** | ❌ 无 | 文字或**截图** → 结构化待办，自带 Key、默认关闭 |
| **提醒方式** | 只有通知 | 通知 **或全屏闹钟**（循环铃声 + 震动 + 延迟），四套配色；另有可靠性自检与系统闹钟入口 |
| **课表数据源** | 本科教务单源 | **双来源**：教务拿不到时改用智慧研工；两个都拿不到时**沿用上一次的课表**，不清空 |
| **开学前看课表** | 显示「无学期信息」 | 显示新学期课表，并提示开学日期 |
| **数据备份** | ❌ 无 | ✅ JSON **导出 / 导入**（按 `uid` + 更新时间合并，删除留墓碑） |
| **出问题的排查** | 诊断日志 | 诊断日志 + **刷新数字**（接口返回几行 / 解析入库几条 / 能显示几条） |
| **电脑上操作待办** | ❌ 无 | 局域网直连网页端（**本版尚未开放**，见「已知问题」） |
| **包名** | `xyz.nosig.celechron` | `xyz.nosig.celechron.mod` —— **可与官方版共存** |

> 上表每一行都能在源码里对上：上游 1.3.0 的 `Task` 模型**没有** priority / attachment /
> tags / subtask / reminder 字段，仓库里也**没有** `lib/mod/` 目录、
> 更没有标签管理、筛选面板、时间面板、闹钟主题这些文件 —— 它们都在本仓库里。

## 三、数据迁移

**从官方版迁过来**：课表、成绩、考试、作业、素质拓展、校园卡 **登录同一个学校账号就有**，
不用搬。要手动处理的只有你自己手写的待办 —— 官方版**没有数据导出功能**，这部分只能重建：
建议在待办页截图，再用 AI 整理识别成待办，比手打快得多。

备份与恢复的细节（导出文件里有什么、合并规则、什么时候该导出）见
[docs/MIGRATION.md](docs/MIGRATION.md)。

## 四、已知问题

- 只提供 **arm64** 包
- **局域网直连网页端尚未开放**（手机当服务器、电脑浏览器操作待办）：为后续开发目标，
  当前版本不可使用，设置里没有入口
- **跨网络同步（坚果云 / WebDAV）** 只有预留配置项，功能未实现
- **校历配置**仍依赖上游的公开只读接口，挂了会回退到缓存 / 本地推算，只影响假期与考试周标注
- **AI 功能**需要自备模型服务商的 Key
- **系统闹钟**设出去之后撤销不了，得自己去「时钟」应用删

## 五、后续开发方向

- 多端同步：允许跨不同设备、网络同步与管理待办
- 接入导航 API：更精确地规划预留提醒时间
- 软件风格自定义化、UI 动画优化

## 六、构建

```bash
flutter pub get
flutter build apk --release --target-platform android-arm64 --no-tree-shake-icons
```

> ⚠️ Windows 上**项目路径不能含非 ASCII 字符**（Gradle 会直接拒绝），
> 中文目录下请用 junction / 软链映射到纯英文路径再构建。
> `--no-tree-shake-icons` 是为了绕开 Windows 应用控制策略对 `font-subset.exe` 的拦截。

签名：在 `android/key.properties` 里配置自己的 keystore 即可（该文件已 gitignore），
没有它时会退回 debug 签名以便本地调试。发版的完整清单见 [docs/RELEASE.md](docs/RELEASE.md)。

## 七、隐私

**没有自己的服务器，不收集、不上传任何数据。** 会联网的场景只有：拉取你自己的教务数据、
课表兜底来源（智慧研工）、只读的公开校历接口、检查更新，以及你主动开启的 AI
（局域网同步本版未开放）。逐条说明见 [PRIVACY.md](PRIVACY.md)。
