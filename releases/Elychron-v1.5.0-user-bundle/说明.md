# Elychron v1.5.0 · 用户安装包

按平台分三份，先看这份说明再动手，尤其是 iOS 那部分。

## 文件清单

- `Elychron-v1.5.0-android-arm64.apk` —— Android 安装包（28.5 MB，只需 arm64），传到手机点开安装，允许「未知来源」即可
- `Elychron-v1.5.0-windows-x64.zip` —— Windows 桌面版（解压后双击 `Elychron.exe`，绿色免安装）
- `Elychron-1.5.0.1-ios.ipa` —— iPhone / iPad 安装包（13.3 MB），**不能直接安装**，必须先自签
- `Elychron-1.5.0.1-ios.ipa.sha256` —— 上面那个 IPA 的校验值
- `iOS自签安装教程.html` —— 自签教程，双击用浏览器打开即可（也可以打印成 PDF）
- `iOS自签安装教程.pdf` —— 同一份教程的 PDF 版，方便发到手机上边看边做
- `iOS自签安装教程.md` —— 教程的纯文本版，给需要复制粘贴的人

## Android

Elychron 的包名和官方 Celechron 不同，**两者可以共存**，装它不会覆盖官方版。

## Windows

解压 zip，双击里面的 `Elychron.exe` 就能用，不需要安装。整个文件夹要一起保留，exe 旁边的 dll 和 `data` 目录都是运行需要的。

## iPhone / iPad

我们没有苹果开发者账号，iOS 版需要你用**自己的 Apple 账号签一次名**。不需要 Xcode，也不需要懂编程，但要知道：免费账号签出来的应用 **7 天后打不开**，重新签一次即可（数据还在）；免费账号同时最多 3 个应用标识，Elychron 正好用满。完整步骤见同目录的 `iOS自签安装教程.html`。

装之前建议核对 IPA 的校验值：Windows 用 `certutil -hashfile 文件名 SHA256`，macOS 用 `shasum -a 256 文件名`，结果应与 `.sha256` 文件里的那串一致。

## 数据与隐私

待办、课表、设置只存在你自己的设备上，同步走你自己的网盘（WebDAV）。换设备或重装前，先在「设置 → 导出数据」留一份 JSON 备份。Elychron 没有服务器，也不收集任何数据。
