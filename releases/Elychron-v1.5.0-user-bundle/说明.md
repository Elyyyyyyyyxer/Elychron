# Elychron v1.5.0 · 用户安装包

这个文件夹里的东西按平台分三份。安装前先看这份说明，尤其是 iOS 部分——它和其他两个平台不一样。

## 文件清单

- `Elychron-v1.5.0-android-arm64.apk` —— Android 安装包（28.5 MB，只需 arm64，近年的校园机型都支持）
- `Elychron-1.5.0.1-ios.ipa` —— iPhone / iPad 安装包（13.3 MB）**不能直接安装**，必须先自签
- `Elychron-1.5.0.1-ios.ipa.sha256` —— 上面那个 IPA 的校验值
- `iOS自签安装教程.md` —— 自签的完整步骤，面向完全没接触过的人

## Android

把 APK 传到手机上点开安装。系统会提示「安装未知来源应用」，允许即可。Elychron 的包名和官方 Celechron 不同，**两者可以共存**，装它不会覆盖官方版。

## iPhone / iPad

我们没有苹果开发者账号，所以 iOS 版需要你用**自己的 Apple 账号签一次名**才能装。整个过程不需要 Xcode，也不需要懂编程，但有几件事要先知道：免费账号签出来的应用 **7 天后会打不开**，需要重新签一次（数据还在）；免费账号同时最多 3 个应用标识，Elychron 正好用满。

完整步骤见同目录的 `iOS自签安装教程.md`。装之前建议先核对一下 IPA 的校验值（Windows 用 `certutil -hashfile 文件名 SHA256`，macOS 用 `shasum -a 256 文件名`），应当与 `.sha256` 文件里的那串一致。

## Windows

暂时没有提供 Windows 安装包。桌面版的构建脚本和说明在仓库的 `docs/desktop-build.md`（如无此文件则以 README 的「六、构建」为准），需要自行编译。

## 数据与隐私

待办、课表、设置都只存在你自己的设备上，同步走你自己的网盘（WebDAV）。换设备或重装前，先在「设置 → 导出数据」留一份 JSON 备份。Elychron 没有服务器，也不收集任何数据。
