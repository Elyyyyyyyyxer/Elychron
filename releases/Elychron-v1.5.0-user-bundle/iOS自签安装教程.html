iPhone / iPad 安装 Elychron

跟着做大概十分钟。全程不需要 Xcode，也不需要会写代码。

开始之前，先知道三件事

  • 没有苹果开发者账号，所以要用你自己的 Apple 账号给它签一次名，这一步叫「自签」。
  • 免费账号签出来的应用 7 天后打不开，重新签一次就好，数据不会丢。
  • Elychron 会占用 3 个应用标识（主应用、分享扩展、小组件），免费账号一共只有 3 个，所以同时装不了别的自签应用。

准备

一台电脑（Windows 或 macOS 都行）和数据线；一个 Apple 账号（平时用的 iCloud 账号就行）；Release 里的那个 .ipa 文件。

推荐用 AltStore Classic 自签：电脑上装 AltServer，手机上装 AltStore。官方安装说明：macOS 见 faq.altstore.io/altstore-classic/how-to-install-altstore-macos，Windows 见 faq.altstore.io/altstore-classic/how-to-install-altstore-windows。

八步装好

  1. 在电脑上安装 AltServer。装好打开，它会常驻在任务栏（Windows）或菜单栏（macOS）。
  2. 用数据线连上 iPhone / iPad，手机上点「信任此电脑」。
  3. 在 AltServer 菜单里选 Install AltStore，选中你的设备，然后输入你自己的 Apple 账号。密码只填在你自己电脑上，我们不会也不需要它。
  4. 手机上会出现 AltStore 图标。第一次打开若提示「不受信任的开发者」，进 设置 → 通用 → VPN 与设备管理 信任你的证书；iOS 16 起还要在 设置 → 隐私与安全性 里打开开发者模式并重启手机。
  5. 把 Elychron 的 .ipa 存到手机的「文件」App（微信、AirDrop、网盘都行）。
  6. 打开 AltStore → My Apps → 右上角加号 → 选那个 IPA。
  7. 如果它问要不要保留扩展，两个都保留：ShareExtension 和 WidgetExtensions。删掉的话照片分享和桌面小组件就不能用了。
  8. 装完打开 Elychron，重新登录学校服务、授权通知。想用原生闹钟需要 iOS 26 及以上，并在系统里给闹钟权限。

之后隔一段时间打开 AltStore 看一眼 My Apps 里的过期倒计时，快到期时用 AltServer 刷新签名，手机和电脑在同一 Wi-Fi 下就行。

遇到问题看这里

装的时候报错，或者一直转圈

先查三样：电脑上 AltServer 开着吗、手机和电脑在同一个 Wi-Fi 吗、iOS 的开发者模式打开了吗。

7 天后打不开

签名过期，不是应用坏了。重新刷新签名即可，数据和登录状态都在。

换了 Apple 账号，或者从 Xcode 安装换到 AltStore

可能被当成一个新应用装上去，旧容器和钥匙串里的登录信息不保证迁移。装之前在旧版本里用「设置 → 导出数据」留一份 JSON 备份，旧应用先别删。

登录一直失败，或者小组件读不到数据

有些签名工具（例如爱思助手）会去掉共享钥匙串权限。Elychron 启动时会实际检查，读不到就改用系统私有钥匙串，登录通常还能用；这种时候照片分享和小组件不可用。用 AltStore 保留扩展权限一般不会遇到。

校园服务连不上

确认手机自己在校园网或学校 VPN 里，不能借电脑的代理。
