# 需要填的下载链接（填好后我一次替换）

现在网站上未知的镜像都显示成「待填」，把下面这些给我（或你自己在 index.html 里搜 `待填` 替换），我一次性填好：

## 1. GitHub 镜像
- 你平时用的那个（例如 `https://kkgithub.com/...`、`https://ghproxy.net/...`、`https://hub.fastgit.xyz/...`）
- 用途：GitHub 打不开时的备用入口

## 2. Gitee
- 仓库地址（例如 https://gitee.com/你的用户名/elychron）
- 如果只是同步 Releases，给我 Releases 页地址就行

## 3. 蓝奏云
- 分享链接（形如 https://xxx.lanzouo.com/xxxxxx 或 https://www.lanzou.com/...）
- **密码**（蓝奏云经常要，填在这里我会显示成"密码 xxxx"）
- 建议：Android 一个链接、Windows 一个链接（或者一个总文件夹链接）

## 4. 百度网盘
- 分享链接（含 `?pwd=` 也行，我会把提取码单独显示）
- **提取码**（4 位）
- 建议同上：分平台给，或给一个总目录

---

## 补充说明（填的时候顺手想一下）
- **更新频率**：GitHub 是你主要发布的地方，Gitee/网盘是"搬运"；如果想让网站自动指向最新版，最省事的做法是
  Gitee/蓝奏云/百度网盘都用**固定链接**（文件夹链接，往里换文件），这样网站不用改。
- **百度网盘限速**：建议在文案里保留"可能限速"的提示（现在已经写了）。
- **蓝奏云免费版限制**：单文件 100 MB 以内、有下载次数限制，我们的 APK 28.5 MB 没问题 ✓。
- 需要的话我还可以加一个「**校验值**」行（SHA-256），下载完能核对完整性 —— 要的话我把 APK 的哈希算出来放上去。
